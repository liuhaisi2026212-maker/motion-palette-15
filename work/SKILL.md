# 十五画境 · Motion Palette 15（v0.3）

每种风格都是一支已经做好的 10 秒成片（获奖级质感，来自 [mg-styles-15](https://github.com/Vincentwei1021/mg-styles-15)，MIT）。片子里的**文字和配色**抽成了配置，画面、动作、配乐不变。

**你的工作只有一件：写配置。不要从零写动画代码，也不要改 `demos/` 里的源码。**

## 第一步：选风格

| id | 风格 | 适合 | 主要能改 |
|---|---|---|---|
| 01-flat-vector | 扁平矢量 | 品牌片头、产品介绍 | 品牌名、中英标语、四格小词、6 个颜色 |
| 02-line-art | 线条动画 | 高级感品牌、工作室、文旅 | 品牌名、标语、线条色、底色 |
| 03-isometric | 等轴 2.5D | 平台、增长数据、生态 | 立体大字、标语、三张数据卡片 |
| 05-cel-boil | 逐帧手绘 | 手作、文创、知识栏目 | 2–4 个汉字标题（按笔顺手写）、英文小标、标语 |
| 06-collage | 拼贴剪贴 | 脑洞、创意、杂志栏目 | 四个剪报大字、中英刊名、多处小字 |
| 07-liquid | 液态流动 | 饮品、美妆、潮玩 | 正好 4 个字的果冻字（中英都行）、标语 |
| 08-morph | 形变动画 | 讲一个过程、一段旅程 | 英文品牌名、7 个场景词、标语、5 个颜色 |
| 09-bauhaus | 包豪斯 | 态度品牌、展览 | 竖排英文大字、三组中英词、色块标签、油墨色 |
| 10-synthwave | 复古 Synthwave | 复古、夜生活、音乐、汽车 | 铬金大字（中英）、霓虹手写字、顶部小字 |
| 12-aurora-glass | 弥散玻璃 | AI 产品、App、科技 | 品牌名、标语、卡片里整段 AI 对话、7 个光斑色 |
| 18-hanazi | 综艺花字（竖屏 1080×1920） | 抖音开头 | 20 多条花字（字数固定）、栏目名、期数 |
| 19-paperclip | 贴纸人科普 | 知识科普 | 只能改标题类文字（内容固定为「手机里的元素」） |
| 20-pixel | 像素风 | 游戏化栏目、闯关活动 | 标题、彩带字、对话框台词 |
| 22-hud | 赛博 HUD | 科技、数据、悬念揭晓 | 系统名、锁定大字 |

（04 3D 渲染需要 Blender 重新渲染，暂不支持。）

用户没指定风格时，按用途推荐 2–3 个让用户选，不要自己闷头定。

## 第二步：写配置

每种风格能改哪些字段、每个字段多少字，以 `mp/styles.js` 里的 `fields` 为准（`example` 是一份完整示例）。工作台里每种风格的「复制给AI的提示词」按钮会生成这份说明。

规则：
- **字数不能超过限制**，标「正好 N 个」的必须正好 N 个（片子是按字排版的，超了会挤、少了会空）。
- 颜色写 `#RRGGBB`；没把握的字段就不写，会用原片的值。
- 文案说人话、短、无错别字；中文标点用全角。品牌名用用户自己的，不要用别人的商标。

## 第三步：出片

两种方式，按你的能力选：

**A. 让用户自己点（任何 AI 都适用）**：把 JSON 发给用户，告诉用户双击 `启动工作台`（苹果电脑 `.command`，Windows `.bat`），在网页里选风格、点「JSON」页粘贴、点「导出 MP4」。

**B. 你能跑命令时**：在本文件夹里用本地服务或渲染脚本导出：
```bash
node mp/server.mjs 7915          # 开工作台（浏览器打开 http://127.0.0.1:7915/）
```
或者直接用原项目的渲染脚本（需要 ffmpeg，画质最高，带动态模糊）：
```bash
node harness/render.mjs demos/01-flat-vector --query 'cfg={"brand":"liuye"}' --audio demos/01-flat-vector/music.m4a --out 成片.mp4
```
先用 `--stills 2,5,9.5` 导出几张静帧看一眼（字有没有挤、颜色对不对），再出整片。

导出没成功就如实说，不要说「视频已生成」。

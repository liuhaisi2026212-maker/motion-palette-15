# 踩坑清单（都是真实做过、真实翻过车的）

每条：**症状 → 原因 → 怎么改**。

## 画面

1. **主体太小，画面空荡荡** → 习惯性把东西画在中间一小块 → 主角 / 主要信息至少占画面高度 1/4；像素风用更小的内部画布（240×135 放大 8 倍）让角色变大。
2. **远山、背景出现一条条竖纹，像条形码** → 用「隔一列画一次深色」做阴影 → 阴影用抖动矩阵（`bayer(x, y)`）或按坡度分面着色。
3. **图标和底色撞色，图标看不见** → 图标颜色写死，底色又在换 → 画图标前检查底色，颜色相同就换成别的颜色。
4. **高亮的关键词被断行切成两半** → 自动换行不知道哪些字是一组 → 换行时不在高亮词内部断开；或者手动指定换行位置。
5. **第二行只剩一两个字（孤字）** → 贪心换行 → 两行时把断点放到中间附近（`wrapText` 已处理）。
6. **字压在别的元素上 / 字被 HUD、血条挡住** → 各自定位，没检查重叠 → 每一拍画完都出静帧看；字幕放在固定的安全区域。
7. **字体没加载出来，渲染成宋体或方块** → 没等字体加载完 → `fonts` 里列出所有要用的字，`document.fonts.load()` 等完再渲染；中文字体一定要把要用到的字传进去。
8. **画面糊** → 像素风用了平滑缩放，或 Canvas 尺寸和显示尺寸不一致 → 像素风 `imageSmoothingEnabled = false` 且整数倍放大；Canvas 的 width/height 设成真实输出尺寸。
9. **渐变出现一圈圈色带** → 8 位颜色不够细 → 叠 3%～5% 的颗粒。
10. **全片一个速度，没有节奏** → 每一拍都用同样的时长和缓动 → 快慢交替；高潮那一拍最快最满，之后留一拍静的。
11. **每样效果都加一点，结果很脏** → 堆效果 → 一个风格只用它需要的 3～5 个手法，做干净。

## 动画

12. **动作僵硬** → 全是线性插值 → 换成 `outCubic`、`outBack`、`spring`；加预备和回弹。
13. **所有元素同时出现** → 没错峰 → 每个晚 2～4 帧。
14. **形变时图形打结、翻面** → 两个形状的顶点数不同、起点不对应 → 两个形状都重采样成同样数量的点（比如 128 个），按角度对齐起点；复杂形状先变成圆再展开。
15. **转场时闪一帧黑 / 闪一帧上一场** → 转场判断用了 `<` 和 `<=` 不一致 → 每个时间点只属于一个镜头，转场期间两个镜头都画。

## 导出

16. **导出的视频卡顿、掉帧** → 用了「边播边录」（屏幕录制、MediaRecorder） → 用逐帧渲染：一帧一帧算好再编码（脚手架的导出就是这样做的）。
17. **导出的片子时长和内容对不上** → 切换片子时，旧页面还没卸载完就被当成新页面 → 加载新页面时带一个版本号，只认这次加载的页面。
18. **片子还没加载完就点了导出，结果卡死** → 导出时页面正在重新加载 → 加载完成前禁止导出，导出过程中禁止改内容。
19. **HTML/CSS 拼的画面导不出视频**（Chrome 报「tainted」） → 浏览器不允许把含 HTML 的 SVG 画进视频帧 → 一开始就用 Canvas 画；实在要用 HTML，只能用无头浏览器截图（`tools/render.mjs`）。
20. **直接双击 html 打开是白屏** → 浏览器不允许本地文件加载 JS 模块 → 用本地服务打开（`启动.command` / `启动.bat`）。
21. **每次导出画面都有一点点不一样** → 用了 `Math.random()` 或实时时间 → 用带种子的随机数，只依赖 t。
22. **声音和画面对不上** → 音效时间是手估的 → 音效时间直接用节拍表里的变量（`m.pop(B.title.t0 + .15)`），和画面用同一个数。

## 内容

23. **片子看起来像别人的作品** → 照着参考片子的画面、构图、角色、文案做 → 只学手法；故事、角色、构图、品牌名都按用户的主题重新设计。
24. **文字说得像广告** → 堆形容词、标题党 → 说人话，一句一个意思，短。
25. **一条片子塞了太多信息** → 每一拍都想讲一件事 → 整片只讲一件事，10 秒最多 3～4 个信息点。

## 做 15 支样片时新踩的坑
- **点画不出来**：中心线长度为 0 时，Chrome 不画圆头描边 → 检测到长度为 0 就改成 `arc` 画实心圆。
- **元球中心有黑点**：用 `r²/d²` 当场，中心值爆掉、梯度乱 → 改用有界核 `(1 - d²/R²)³`，阈值 0.3。
- **形变 / 果冻字有横向台阶纹**：逐行加整数像素偏移做抖动 → 去掉，或用双线性插值采样。
- **淡出不生效**：子函数里写了 `ctx.globalAlpha = 1` 把外层透明度冲掉 → 一律 `save/restore`，或者乘上外层的值。
- **镜头平移后内容跑出画面**：大画布 + 镜头平移时，后面要动画的元素要放在新机位看得到的位置，出静帧时按每个机位各看一张。
- **漏掉风格的「骨架」**：先对照风格卡的「最容易做成不像的原因」搭版式，再做细节。

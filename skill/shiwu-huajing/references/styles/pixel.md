# 像素风

## 一眼认出它
低分辨率的大颗粒像素、硬边、有限色板，精灵角色一顿一顿地跑跳（10～12fps），天空是抖动渐变，背景几层视差卷轴，对话框里是像素中文，偶尔有显像管扫描线。

## 适合 / 不适合
适合：游戏化内容、闯关升级类叙事、怀旧、系列栏目、年轻品牌。不适合：高级感、写实。

## 必备元素
1. **小画布整数倍放大**：内部 240×135（放大 8 倍到 1080p）或 320×180（放大 6 倍），`imageSmoothingEnabled = false`。所有坐标取整。
2. **有限色板**：16～32 色，全片只用色板里的颜色。
3. **抖动渐变**：天空、阴影用拜耳矩阵在两色之间抖动，不用平滑渐变。
4. **跳帧动画**：精灵 10～12fps 换帧；位置也按帧取整，不用平滑缓动。
5. **视差卷轴**：远山、丘陵、树、地面 3～4 层，按 0.2 / 0.45 / 0.7 / 1 的速度整像素平移。
6. **像素字**：中文用 Fusion Pixel（OFL），英文用 Press Start 2P；字要先阈值化成硬边（`pixelText` 已处理）。
7. **游戏语法**：HUD（血量、金币、关卡）、对话框（双层边框 + 打字机）、顶砖块、开宝箱、升级、通关旗杆。

## 色板（示例 16 色，原创）

## 技术路线
Canvas 2D：在小画布上逐像素画，最后一次性放大到大画布；扫描线、暗角在大画布上加（不影响像素）。

```js
const LOW = pixelCanvas(240, 135), K = 8;
// 精灵：字符画 → 图片，每个字符对应色板里的一个颜色
const HERO = sprite([
  '....kkkkk...', '...kcccwck..', '..kcccccccck', '..khssssskk.', '..khsesesk..', '...kssssk...',
  '..krbbbbbk..', '.krRbbbbbbk.', '..kppppppk..', '..kpppkpppk.', '..kook.kook.', '..kkk...kkk.',
], { k: '#0B0D1A', c: '#4B6FC4', w: '#FFFFFF', h: '#4A2E22', s: '#F1C99B', e: '#0B0D1A', r: '#C2415A', R: '#6B2F4F', b: '#FFB26B', p: '#33407A', o: '#4A2E22' });
// 跳帧：12fps
const f = Math.floor(t * 12);
// 抖动天空
for (let y = 0; y < 110; y++) for (let x = 0; x < 240; x++) { const u = y / 110; LOW.ctx.fillStyle = u > bayer(x, y) ? '#6FA8F0' : '#B8E1FF'; LOW.ctx.fillRect(x, y, 1, 1); }
// 画完小画布后：
blitPixels(ctx, LOW);
ctx.fillStyle = 'rgba(0,0,0,.1)'; for (let y = 0; y < 1080; y += K) ctx.fillRect(0, y + K - 2, 1920, 2);   // 扫描线
```

（逐像素画天空很慢：在 `setup` 里画一次存起来，每帧 `drawImage` 复用。）

## 最小可行做法（一般模型）
1. 240×135 小画布：抖动天空（预渲染）+ 两层山（折线填色）+ 地面砖块。
2. 一个 12×16 左右的主角精灵，2～4 帧跑步循环。
3. 4～6 个镜头：标题（像素大字放大 3 倍从天上掉下来）→ 奔跑跳过障碍（世界卷动、主角位置不动）→ 对话框打字 → 开宝箱（光芒）→ 通关大字。
4. 镜头之间用格子转场（一格格黑方块从左上铺到右下）。
5. 8-bit 配乐：方波旋律 + 三角波贝斯 + 噪声鼓。

## 进阶做法（强模型）
- 天色随剧情变化（白天 → 黄昏 → 夜晚），换整套色板。
- 打怪：怪物血条、主角扔道具、怪物闪烁、爆成像素碎片。
- 显像管效果：桶形畸变 + 荧光辉光（WebGL 后期），但不能把像素糊掉。

## 常见做砸
- 角色太小（240×135 内部画布下，角色至少 14×16 像素）。
- 用了平滑缩放、非整数坐标——边缘发糊。
- 用 canvas 直接写中文，边缘有半透明灰边（要阈值化）。
- 阴影用「隔一列画一次」，出现竖条纹（用抖动矩阵）。
- 精灵平滑移动（要按帧跳）。

## 配乐
Chiptune：方波 / 25% 脉冲波旋律、三角波贝斯、噪声做鼓；音效：跳（方波上滑）、金币（两个高音）、开宝箱（上行琶音）、升级（快速琶音）。

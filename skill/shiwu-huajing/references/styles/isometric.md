# 等轴 2.5D

## 一眼认出它
从斜上方 30° 看下去的小世界（城市、办公室、机房），**没有透视**：远处的东西不会变小，所有平行线还是平行。楼一栋栋「长」出来，小车在路上跑。

## 适合 / 不适合
适合：平台生态、系统架构、产品功能演示、城市、数据中心、流程。不适合：情绪、人物特写。

## 必备元素
1. **真等轴投影**：x 轴、y 轴都和水平线成 30°，没有灭点。
2. **地块网格**：场景放在一块悬浮的地台上，地台有厚度。
3. **楼房生长**：底面先落位 → 墙面从 0 拉高（带回弹）→ 顶面晚 2～3 帧盖上。
4. **三面明暗**：顶面最亮、左面中等、右面最暗（光从一个固定方向来）。
5. **生活感**：小车沿路跑、风车转、窗户依次亮、数据流在楼之间跳。
6. **平行运镜**：镜头只平移、缩放，不旋转。

## 配色
- 粉彩工作室：底 `#E9E4FF` → `#B8A8F0`（渐变底，这一种风格可以用柔和渐变），地面 `#F4F2FF`，楼 `#FFFFFF`/`#C9C9FF`，点缀 `#7ED3B2` `#FFB4A2` `#6FA8FF`
- 夜城：底 `#14143A`，地面 `#2A2A5A`，楼 `#3D3D7A`，窗 `#FFD166`，点缀 `#4FD1C5`

## 字体
几何无衬线粗体（Unbounded、Poppins、思源黑体 Heavy）。标题可以「躺」在地面上（同样做等轴变换）。

## 动画语法
- 地块：从中心往外一圈圈翻 / 落下，每块小回弹，间隔 1～2 帧
- 楼：`scaleY` 用 `spring`，顶面延迟 2～3 帧
- 运镜：长尾缓动，最后拉远看到整个悬浮的岛

## 技术路线
Canvas 2D 自己算投影（一般模型够用），或 Three.js 正交相机（强模型，`camera.position` 设在 (1,1,1) 方向，45° 方位、35.264° 仰角）。

```js
// 等轴投影：世界坐标 (x, y 地面, z 高度) → 屏幕
const ISO = { cx: 960, cy: 620, s: 40 };   // s：一个格子的屏幕宽度的一半
const iso = (x, y, z = 0) => [ISO.cx + (x - y) * ISO.s, ISO.cy + (x + y) * ISO.s * .5 - z * ISO.s];
// 画一个方块（x,y 格子位置，w,d 占几格，h 高度格数），顶面亮、左面中、右面暗
function box(ctx, x, y, w, d, h, color) {
  const P = (a, b, c) => iso(a, b, c), poly = (pts, fill) => { ctx.beginPath(); pts.forEach(([px, py], i) => i ? ctx.lineTo(px, py) : ctx.moveTo(px, py)); ctx.closePath(); ctx.fillStyle = fill; ctx.fill(); };
  poly([P(x, y + d, 0), P(x + w, y + d, 0), P(x + w, y + d, h), P(x, y + d, h)], shade(color, -.12));   // 左前面
  poly([P(x + w, y, 0), P(x + w, y + d, 0), P(x + w, y + d, h), P(x + w, y, h)], shade(color, -.28)); // 右前面
  poly([P(x, y, h), P(x + w, y, h), P(x + w, y + d, h), P(x, y + d, h)], shade(color, .12));           // 顶面
}
// 遮挡：按 (x + y) 从小到大画（远的先画）
```

（`shade(颜色, 正数变亮/负数变暗)` 自己写一个，或者直接给三个颜色。）

## 最小可行做法（一般模型）
1. 一块 8×8 的地台（`box` 画薄板），地台下面加一层厚度和阴影。
2. 5～8 栋楼按顺序长出来（高度用 `spring`，每栋晚 3 帧）。
3. 每栋楼正面画几排小窗户（小平行四边形），在某一刻依次点亮。
4. 一条路上一个小方块（小车）匀速循环跑。
5. 结尾大字放在画面上方（不用做等轴变形），整个场景缓慢放大 5%。

## 进阶做法（强模型）
- Three.js 正交相机 + 柔和阴影 + 环境光遮蔽，材质用纯色 `MeshStandardMaterial`，粗糙度 0.8。
- 数据卡片：从楼顶升起一根细线，末端弹出一张小卡片（数字滚动）。
- 标题做成等轴变形贴在地面上（Canvas 的 `setTransform` 用等轴矩阵）。
- 视差：前景云、中景城、背景渐变按 1 : 0.8 : 0.6 的速度移动。

## 常见做砸
- 用了透视（远处变小），就不是等轴了。
- 画的顺序错了，后面的楼盖住前面的楼。
- 三个面颜色差太小，看不出立体。
- 镜头旋转。

## 配乐
明亮的科技感拨弦 / 马林巴，每块地、每栋楼落地配一个轻 click / pop，拉远时一个空气感 whoosh。

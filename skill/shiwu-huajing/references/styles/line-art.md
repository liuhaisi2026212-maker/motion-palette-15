# 线条一笔画

## 一眼认出它
深色底上**一根恒定粗细的细线**自己往前画，转个弯就变成了下一个东西：种子 → 树 → 楼 → 天际线 → logo。极简、安静、高级。

## 适合 / 不适合
适合：高端品牌、设计工作室、建筑地产、文旅、金融、logo 演绎。不适合：信息多、要热闹的内容。

## 必备元素
1. **一根线贯穿全片**：上一个图形的尾巴就是下一个图形的开头，不断开。
2. **线宽全程恒定**（2～4px，1080p），圆头圆角（`lineCap = lineJoin = 'round'`）。
3. **单色或双色**：深底（`#0B1320`、近黑）+ 一种亮线色（香槟金 `#E9D7A5`、冰蓝、薄荷）。
4. **发光的笔尖**领着线走（一个亮点 + 柔光）。
5. **大量留白**。
6. **结尾「线转面」**：logo 描完轮廓后从某个点开始填满颜色，然后出细的、加宽字距的衬线字。

## 配色
- 香槟金：底 `#0B1320`，线 `#E9D7A5`，笔尖 `#FFF6DC`
- 冰川：底 `#0E1A1F`，线 `#9FE3D0`，笔尖 `#E8FFF9`
- 纸墨（反过来）：底 `#F3EEE4`，线 `#1C1C1C`，强调 `#C8553D`

## 字体
细衬线、大字距：Cormorant Garamond / Playfair Display，中文用思源宋体 Light。字距 0.3～0.5em，全大写。

## 动画语法
- 描绘速度：`cubic-bezier(0.65, 0, 0.35, 1)`；转角处放慢（按曲率降速）
- 镜头跟着笔尖缓慢漂移、推近；结尾拉远看到整幅画
- 已经画过的部分可以慢慢暗到 35%，让视线跟着笔尖

## 技术路线
把整条路径写成**一个点列表**（折线），按累计长度取前 L 长度画出来：

```js
// 预先算：pts 是整条线的点 [[x,y], ...]，len[i] 是到第 i 个点的累计长度
function drawUpTo(ctx, pts, len, L) {
  ctx.beginPath(); ctx.moveTo(pts[0][0], pts[0][1]);
  for (let i = 1; i < pts.length; i++) { if (len[i] > L) { const f = (L - len[i - 1]) / (len[i] - len[i - 1]); ctx.lineTo(lerp(pts[i - 1][0], pts[i][0], f), lerp(pts[i - 1][1], pts[i][1], f)); return [lerp(pts[i - 1][0], pts[i][0], f), lerp(pts[i - 1][1], pts[i][1], f)]; } ctx.lineTo(pts[i][0], pts[i][1]); }
  return pts[pts.length - 1];
}
ctx.lineWidth = 3; ctx.lineCap = ctx.lineJoin = 'round'; ctx.strokeStyle = GOLD;
const tip = drawUpTo(ctx, PTS, LEN, totalLen * E.inOutCubic(seg(t, 0.3, 8))); ctx.stroke();
glow(ctx, '#FFF6DC', () => circle(ctx, tip[0], tip[1], 5, '#FFF6DC'), 24, 6);   // 发光笔尖
```

路径怎么来：用直线段 + 圆弧 + 贝塞尔拼出图形（`Path2D` 或自己采样成点），每段首尾相接。

## 最小可行做法（一般模型）
1. 只画 3 个图形连成一条线：比如「一条地平线 → 一座房子轮廓 → 一个圆形 logo」。
2. 线条用上面的 `drawUpTo` 按时间画出来，笔尖加光点。
3. 结尾 logo 圆形填充，从中心扩开（`circle` 半径从 0 长到满）。
4. 品牌名用细衬线字，逐字淡入、字距从宽收到正常。

## 进阶做法（强模型）
- 用 SVG 路径字符串 + `getTotalLength()`/`getPointAtLength()` 采样，路径更复杂（植物、城市天际线、海浪）。
- 线的「手绘感」：路径加极小的噪声抖动（1px 内）。
- 虚拟镜头：画面坐标乘一个跟随笔尖的平移缩放矩阵（推近 1.3 倍、长尾缓动），结尾拉回 1.0 倍。
- 线转面：用同一条闭合路径做 `clip`，在里面画一个从锚点扩散的圆。

## 常见做砸
- 线是一段一段断开的，看不出「一笔」。
- 线宽忽粗忽细（缩放镜头时要用 `lineWidth / 缩放倍数` 保持屏幕上恒定）。
- 画得太满，没有留白。
- 整页一起淡入，而不是被「画」出来。

## 配乐
极简钢琴 + 弦乐铺底，笔尖走动配很轻的沙沙声（噪声，音量跟着笔尖速度），线转面时一声清脆的风铃 / ding。

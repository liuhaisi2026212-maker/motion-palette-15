# 赛博 HUD（科幻界面）

## 一眼认出它
科幻电影里的**指挥舱屏幕**：画面四周有细外框和顶栏，左右两列编号的数据面板塞满小字、数字和曲线，正中一个大罗盘瞄准镜**罩在一个被观察的东西上**（地球、城市、街区、飞船）。先开机自检，再雷达扫描、数字乱跳、候选比对，然后锁定框收紧，**全屏从青色切成琥珀色**，横贯画面的锁定带写着「目标锁定 / LOCKED」，镜头俯冲放大到目标，最后上传数据、关机。

一句话：**信息铺满整屏，但只有一个焦点；所有东西都在为「锁定」那一下蓄力。**

## 适合 / 不适合
适合：科技、数据、AI、悬念揭晓、「找到了」类内容（找爆款、找原因、找人找物）、游戏、产品发布倒计时。不适合：温情、生活化内容。

## 最容易做成「不像」的原因（先看这个）
只做了一个雷达加两个小面板，画面中间大片空着——那是「雷达屏保」，不是 HUD。HUD 的感觉来自三样东西，缺一样就不像：
1. **被观察的主体**：瞄准镜里必须有东西（地图、地球、建筑线框）。雷达不能扫空白。
2. **满屏的信息密度**：左右两列各 3～4 个面板，从上铺到下；四周有读数、顶栏、底部航向带。
3. **完整的锁定戏**：扫描 → 发现信号 → 候选比对（前两个 NO MATCH，第三个 MATCH）→ 锁定框飞过来 → 变色 + 锁定带 + 冲击波 → 俯冲放大。

## 时间表（10 秒，照这个节奏，每个点都配一个声音）
| 秒 | 发生什么 |
|---|---|
| 0～0.3 | 开机：画面从中间一条亮横线上下展开 + 故障闪 |
| 0.12 / 0.4 / 0.55 / 0.7 | 外框 → 外圈弧（重击声）→ 刻度 → 内圈依次画出 |
| 0.4～1.9 | 自检日志每 0.25 秒一行，每行一声短哔 |
| 0.9 / 1.15 | 左列、右列面板出现 |
| 1.2～2.4 | 六边形网格扩散；1.4 主体（地图）从上往下扫出来 |
| 2.4 | 数据「活了」：数字开始跳、曲线开始滚、雷达扫描开始（2 秒一圈），底鼓进来（120 BPM） |
| 4.4 | 发现信号：一帧闪白 + 故障，目标点开始脉冲，旁边引线标签 `UNK-03` |
| 4.9 / 5.4 / 5.9 | 候选比对：NO MATCH、NO MATCH、MATCH 99.7%（高亮 + 两声高音） |
| 5.9～6.17 | 四个锁定角从大框飞向目标，6.23 收紧一下（咔） |
| **6.4 锁定** | 全屏切琥珀色、闪白一帧、冲击波圆环扩散、横向锁定带展开（左「目标锁定」右「LOCKED」，两端斜线条纹）、警报双音 |
| 6.43～7.7 | 俯冲：主体放大到 3 倍，目标移到正中 |

| 6.9 / 7.4 / 7.9 / 8.4 | 外框警报脉冲 |
| 9.0～9.4 | 数据链进度条走满，`SENT ✓` |
| 9.77～10 | 关机：画面收成一条线 |

## 配色
- 平时青：主色 `rgb(63,230,255)`，所有元素都用它加不同透明度（线 0.35～0.8、字 0.5～1）
- 锁定琥珀：`rgb(255,150,40)`，**锁定那一帧硬切**，不渐变
- 背景：青态 `#04161D`→`#010305`；琥珀态 `#140A03`→`#010305`
- 只有 REC 的小红点用红色

技巧：写一个 `C(a)` 函数返回当前墨色加透明度，锁定前后只改一个变量，整屏一起变色。

## 字体
等宽：JetBrains Mono / SF Mono / Menlo / Consolas；中文：思源黑体 / 苹方 / 微软雅黑。小字 12～15px，大数字 60px，锁定字 54px。

## 技术路线
Canvas 2D 就能做到上面全部效果（参考作品 `examples/films/hud-寻猫雷达/film.js`，约 300 行）。关键写法：

```js
// 1. 当前墨色
let ink = CYAN; const C = (a = 1) => `rgba(${ink[0]},${ink[1]},${ink[2]},${a})`;   // draw 开头：ink = t >= LOCK ? AMBER : CYAN
// 2. 主体放在瞄准镜里：clip 圆 + 变换（俯冲就是改 z 和平移）
ctx.save(); ctx.beginPath(); ctx.arc(CX, CY, RM, 0, Math.PI * 2); ctx.clip();
ctx.translate(CX, CY); ctx.scale(z, z); ctx.translate(-px, -py); /* 画地图，线宽除以 z */ ctx.restore();
// 3. 雷达扫描：锥形渐变 + 一条亮线；光点被扫过时亮一下再慢慢暗
const g = ctx.createConicGradient(a, CX, CY); g.addColorStop(0, C(0)); g.addColorStop(.9, C(0)); g.addColorStop(.995, C(.35)); g.addColorStop(1, C(0));
// 4. 辉光：把整帧拷到离屏画布，模糊后用 lighter 叠回来两次（小模糊 + 大模糊）
buf.getContext('2d').drawImage(ctx.canvas, 0, 0);
ctx.globalCompositeOperation = 'lighter'; ctx.filter = 'blur(8px)'; ctx.globalAlpha = .45; ctx.drawImage(buf, 0, 0); ctx.filter = 'blur(28px)'; ctx.globalAlpha = .35; ctx.drawImage(buf, 0, 0);
// 5. 故障：在几个固定时间点，把几条横向切片错位画回来 + 左右各偏 8px 叠一层
// 6. 扫描线：每 3px 一条 1px 半透明黑线；最后暗角 + 颗粒
```

强模型可选：Three.js 线框地球 + 真正的 bloom 后期 + 色差着色器（原版就是这么做的），但版式和时间表不变。

## 最小可行做法（一般模型）
不要删版式，**删细节**：
1. 外框 + 顶栏三段（系统名 / 阶段标签 / 时间码）。
2. 左列 3 个面板（日志、大数字、遥测），右列 3 个面板（曲线、候选、频谱）。每个面板就是「标题行 + 几行等宽小字」，用一个函数批量画。
3. 中央瞄准镜：两圈弧 + 刻度 + 十字，里面画一张简单的网格地图（几十个矩形当楼）。
4. 雷达扫描 2 秒一圈，扫过的光点亮一下。
5. 6.4 秒锁定：变琥珀、闪白、锁定带、冲击波圆环。
6. 辉光（上面第 4 条）+ 扫描线。

## 进阶做法（强模型）
- 线框地球（d3-geo 投影 + 点阵陆地），扫描时地球转到目标经度。
- 俯冲时主体从地球切到城市街区（两层主体交叉淡化）。
- 锁定瞬间色差加大、辉光半径收紧再放开。

## 常见做砸
- **雷达扫空白**，画面中间空——一定要有被观察的主体。
- 两侧面板太少太大，像 PPT——要多、要小、要密，从上铺到下。
- 字太小糊成一片——小字不低于 12px，关键数字 60px。
- 没有颜色状态切换，或者渐变着变色——锁定那一帧硬切。
- 辉光太强把字糊掉——两次模糊叠加，透明度控制在 0.35～0.45。

## 配乐
低频锯齿波持续音 + 正弦低音垫底；2.4 秒起 120 BPM 底鼓；日志短哔、雷达光点叮、候选比对的提示音、锁定的重击 + 双音警报、上传上行琶音、关机下滑音。

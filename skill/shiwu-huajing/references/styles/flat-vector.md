# 扁平矢量

## 一眼认出它
纯色大色块、几何化的图形和人物、没有渐变、没有描边（或极细），每样东西都是「弹」进来的。像 Google、各种 SaaS 产品的讲解动画。

## 适合 / 不适合
适合：产品介绍、讲方法、讲流程、对比、数据、企业宣传。不适合：要表现质感、情绪很重的内容。

## 最容易做成「不像」的原因（先看这个）
只摆几个图标、几句字——那是 PPT。对照原版，味道来自：
1. **完整的场景插画**：城市天际线（每栋楼有窗格、屋顶小细节、树）、室内工位（人物 + 电脑 + 台灯 + 植物 + 墙上的画 + 窗外的景），层次多、细节密，但每块都是纯色平涂。
2. **一个贯穿全片的小元素**：比如一个橙色圆点——先是太阳，再是窗外的太阳、屏幕上的点、图表顶上的点，最后变成品牌名的句点。镜头之间靠它转场。
3. **分屏**：2×2 四格不同底色，每格一个小场景 + 编号小标题（01 省时 / 02 …）。
4. **颜色少但饱满**：一个大面积主色（如深绿）+ 米白 + 一个强调色（橙），不要彩虹色。
5. **结尾**：品牌名 + 那个圆点 + 一个大圆环扫过，下面中文标语 + 字距拉开的英文小字。

## 必备元素（缺一个就不像）
1. **纯色大色块**做背景和主体，整片 5～6 个颜色，不用渐变。
2. **弹性入场**：每个元素出现都带回弹（冲过头 10%～15% 再回来）。
3. **错峰**：一组元素依次出现，间隔 2～4 帧。
4. **一个贯穿全片的元素**：一个圆点 / 方块 / 图形在各场之间穿梭，带着画面转场（变成太阳、变成按钮、放大成下一场的底色）。
5. **色块转场**：某个形状放大铺满画面，成为下一场的背景。

## 配色（任选一套，或按品牌色换掉主色）
- 薄荷：底 `#0E7C66` / 浅 `#FFF6E9` / 强调 `#FF6B35` / 黄 `#FFD166` / 青 `#2EC4B6` / 深 `#14213D`
- 柠檬：底 `#FFE45E` / 蓝 `#4D96FF` / 红 `#FF5E5B` / 绿 `#6BCB77` / 浅 `#FFF8EC` / 深 `#222831`
- 夜色：底 `#1E1B4B` / 粉 `#F472B6` / 黄 `#FDE047` / 绿 `#34D399` / 浅 `#F8FAFC`

## 字体
圆润的粗体：英文 Fredoka / Poppins，中文 思源黑体 Heavy 或站酷快乐体。标题 900 粗，字号大胆一点（横屏 140～180px）。

## 动画语法
- 回弹：`cubic-bezier(0.34, 1.56, 0.64, 1)` 或 `spring(t, 2.6, 0.42)`，8～12 帧
- 入场三段：预备（往反方向 4 帧）→ 冲出 → 回弹停住
- 挤压拉伸约 10%
- 同一时刻只有一个主体在动
- 30fps

## 技术路线
Canvas 2D（形状用 `roundRect`、`arc`、`Path2D`）。人物：圆头 + 胶囊身体 + 四肢用线段绕关节旋转。

## 最小可行做法（一般模型）
1. 每一场一个纯色背景 + 一个大的主体（图标、数字或一句话）+ 2～3 个小装饰（圆环、加号、波浪线）在四周慢慢漂。
2. 文字用 `popText` 逐字弹出；关键词下面画一条强调色圆角底条，从左往右长出来。
3. 小装饰用 `spring` 依次弹出（每个晚 3 帧）。
4. 每场结尾：贯穿元素（比如一个强调色圆角方块）放大到铺满画面，颜色是下一场的底色。

```js
// 关键词底条：从左往右长出来
const p = E.outCubic(seg(t, t0 + .3, t0 + .65));
rrect(ctx, x - 10, y - size * .75, (w + 20) * p, size * 1.0, size * .12, ACCENT);
// 贯穿元素放大成下一场底色（最后 0.4 秒）
const k = E.inCubic(seg(t, sceneEnd - .4, sceneEnd)), R = k * 2400;
ctx.save(); ctx.translate(cx, cy); ctx.rotate(.12 + k * .6); rrect(ctx, -R / 2, -R / 2, R, R, R * .28, NEXT_BG); ctx.restore();
```

## 进阶做法（强模型）
- 几何人物：关节层级（肩 → 肘 → 手），每个关节绕锚点旋转，加眨眼、点头。
- 一镜到底：画一个比画面大的世界，镜头在里面推拉平移，元素之间靠匹配剪辑串起来。
- 图标的「绘制」动画：对勾用 `setLineDash` 画出来，柱状图从下往上长，爱心弹出，硬币翻转（`scaleX = cos`）。
- 大块几何构图：背景里有一块缓慢移动的大圆、斜条或波浪，给画面层次。

## 常见做砸
- 像 PPT：白底 + 黑字 + 居中，没有色块、没有装饰、没有运动层次。
- 颜色太多太花，或者用了渐变和投影。
- 所有东西同时出现、匀速运动。
- 图标颜色和背景同色，看不见。

## 配乐
明亮的流行 / future bass，110～125 BPM。每个元素入场配 pop，转场配 whoosh，落地配 thud。

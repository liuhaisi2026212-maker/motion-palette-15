# 包豪斯几何

## 一眼认出它
米白纸上，红黄蓝黑的圆、三角、方块、半圆、四分之一圆，严格对齐在网格上，跟着节拍一下一下地转、滑、翻，最后拼成一张海报，配粗体无衬线字。理性、机械、有音乐感。

## 适合 / 不适合
适合：有态度的品牌、展览、音乐、设计类内容、动态海报。不适合：可爱、温情的内容。

## 必备元素
1. **只用基础几何**：圆、三角、正方、半圆、四分之一圆、粗黑条。
2. **红黄蓝黑 + 米白纸**，不加别的颜色。
3. **严格网格**：设一个模数（比如 120px），所有位移都是模数的整数倍，落点都在网格线上。
4. **卡节拍**：选一个 BPM（120 → 每拍 0.5 秒），每一拍有一个元素做一个动作（转 90°、滑一格、翻面、出现）。
5. **缓动克制**：`inOutQuad` 或线性，**禁止回弹**——机械感是特征。
6. **旋转轴心变化**：绕自己中心、绕某个角、绕画面中心，交替使用。
7. **瑞士排版**：粗体无衬线大字（可以竖排），小号全大写说明文字。

## 配色（固定，只调色值不调色相）
纸 `#F1E9DA`、红 `#E03C31`、黄 `#F2B705`、蓝 `#1E4FA3`、黑 `#111111`。

## 字体
Poppins Black / Futura 类几何无衬线；中文用思源黑体 Heavy。说明文字 600 粗、全大写、字距 0.3em。

## 动画语法
```js
const BPM = 120, BEAT = 60 / BPM, M = 120;              // 模数 120px
const beatP = (t, k, dur = BEAT * .5) => E.inOutQ(seg(t, k * BEAT, k * BEAT + dur));   // 第 k 拍的动作进度
// 绕某个角旋转 90°：先移到轴心，转，再移回
function rotAbout(ctx, px, py, ang, draw) { ctx.save(); ctx.translate(px, py); ctx.rotate(ang); ctx.translate(-px, -py); draw(); ctx.restore(); }
// 四分之一圆（扇形），从 (x,y) 角出发
function quarter(ctx, x, y, r, a0, fill) { ctx.beginPath(); ctx.moveTo(x, y); ctx.arc(x, y, r, a0, a0 + Math.PI / 2); ctx.closePath(); ctx.fillStyle = fill; ctx.fill(); }
```

## 技术路线
Canvas 2D 就够。质感：纸纹（`multiply` 8%）+ 印刷错位（每种颜色偏 1～2px）+ 颗粒。

## 最小可行做法（一般模型）
1. 米白纸 + 淡淡的网格线（第一拍画出来）。
2. 8～12 拍，每拍一个几何块出现或动作：红圆落下、黄三角滑进来、蓝方块翻 90°、黑条横扫……都对齐网格。
3. 最后 2 秒停成一张构图完整的海报：左边竖排大字（品牌名），右下小字一行。
4. 每拍配一个 click / 木鱼声，四分音符底鼓。

## 进阶做法（强模型）
- 全画面的方块阵列在高潮时做「相位波」：每格晚一点点翻转，像多米诺。
- 分色印刷：先画到几个单色图层，各自偏移 1～3px 再 `multiply` 合成。
- 数学驱动：用 `sin(t + i * 相位差)` 批量驱动一排几何体。

## 常见做砸
- 加了回弹、加了渐变、加了第五种颜色——立刻不像了。
- 元素随便放，不对齐网格。
- 动作不卡节拍，乱动。

## 配乐
极简电子 / click 节奏，120 BPM：每次翻转一个有音高的短 blip，四分音符底鼓，整体干净。

# 贴纸人科普（知识区包装）

## 一眼认出它
B 站硬核科普常见的包装：实物照片抠出来加一圈粗白边变成「贴纸」，和扁平图标、精确的图表、带引线的标注一起铺在一张很大的浅色画布上，镜头在画布上平移、推拉，一句解说出现一个新元素。冷静、严谨、信息密度高。

## 适合 / 不适合
适合：硬核科普、财经、产品拆解、行业分析、企业介绍。不适合：情绪化、娱乐化内容。

## 必备元素
1. **贴纸化**：照片（或画出来的物件）加 8～12px 白描边 + 柔和投影，统一质感。
2. **冷静的底**：浅蓝灰 / 米白（`#E9EEF2`、`#F3F1EC`），2～3 个主色 + 1 个强调色（橙红 `#FF5A36`）。
3. **一块大画布 + 镜头运动**：所有内容排在一张比屏幕大很多的画布上，镜头长缓动地平移 / 推拉，从一个信息点到下一个，不硬切。
4. **精确的图表**：柱子按比例长、数字滚动计数（最后停在真实值）、路径描边生长、带引线的标注。
5. **一句一个新元素**：每 1.5～2.5 秒有一个新东西出现。
6. **等线体排版**：标题粗、正文常规，对齐严格；数字用大号粗体。

## 配色
- 冷静蓝灰：底 `#E9EEF2`，深字 `#25313D`，次要 `#5E6D7B`，强调 `#FF5A36`，辅助 `#3A86FF`
- 米白：底 `#F3F1EC`，深 `#1F2933`，强调 `#E4572E`，辅助 `#17BEBB`

## 字体
思源黑体（标题 900、正文 500），数字用 Inter / DIN 类粗体。

## 技术路线
Canvas 2D。画布用「世界坐标」，镜头是一个变换：

```js
// 镜头：在世界坐标里，从 A 机位缓动到 B 机位（中心点 + 缩放）
const CAMS = [{ t: 0, x: 960, y: 540, z: 1 }, { t: 3, x: 2600, y: 700, z: 1.4 }, { t: 6.5, x: 1800, y: 1600, z: .8 }];
function camAt(t) { let i = 0; while (i < CAMS.length - 2 && t > CAMS[i + 1].t) i++; const a = CAMS[i], b = CAMS[i + 1], u = E.outExpo(seg(t, a.t, a.t + 1.4)); return { x: lerp(a.x, b.x, u), y: lerp(a.y, b.y, u), z: lerp(a.z, b.z, u) }; }
const c = camAt(t); ctx.translate(960, 540); ctx.scale(c.z, c.z); ctx.translate(-c.x, -c.y);   // 之后都用世界坐标画
// 数字滚动：快速跳 3~5 帧后停在真实值
const shown = t < tEnd ? Math.round(target * E.outCubic(seg(t, t0, tEnd))) : target;
// 引线标注：从物件上的点画一条折线到标签（线用 setLineDash 生长）
```

贴纸白边：照片用 `collage.md` 里的 `cutout()`；画出来的物件直接描一圈粗白边（`lineWidth 20`，`strokeStyle '#fff'`）再填色。

## 最小可行做法（一般模型）
1. 浅色底 + 一个大标题（两行，第二行关键词下画强调色底线）。
2. 一个主物件贴纸（用户照片，或画一个扁平物件加白边）在左边，右边 3 个带引线的标注依次出现。
3. 一个柱状图或大数字：柱子错峰长出来，数字从 0 滚到目标值。
4. 镜头在 3 个机位之间缓动移动（`camAt`）。
5. 结尾一个大数字 + 一句结论 + 小字来源说明。

## 进阶做法（强模型）
- 世界地图（用 TopoJSON + d3-geo 投影画在 Canvas 上），产地连线生长。
- 元素周期表、表格类网格依次点亮。
- 手机/屏幕框里嵌套一层缩小的画面（画中画），镜头穿进去。

## 常见做砸
- 数据不准、柱子不按比例——这个风格的观众最在意。
- 颜色太多太跳。
- 镜头硬切或者动得太快，看不清信息。
- 字太小（手机上看不清）。

## 配乐
干净的科技解说垫乐；UI 点击声、数字滚动的滴答声、镜头移动时轻微 whoosh。

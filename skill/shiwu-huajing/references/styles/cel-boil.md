# 逐帧手绘（线条沸腾）

## 一眼认出它
像手一帧帧画出来的：**线条一直在轻轻抖**（叫 line boil，画面在「呼吸」），动作一顿一顿的（一拍二），暖色纸底，填色和线稿有一点错位，配手绘的烟、火花、速度线。

## 适合 / 不适合
适合：有温度的品牌、手作、文创、儿童、知识栏目片头、可爱的角色。不适合：要冷静、精密感的科技内容。

## 最容易做成「不像」的原因（先看这个）
线条太干净、太工整——就成了矢量动画。对照原版，味道来自：
1. **纸**：米色纸纹底；整个画面放在一块画板上（顶部有夹子、几张纸叠起来的边缘、深色画板边框）。
2. **手绘标牌**：云朵形大红牌子（波浪边、黑色描边有手抖），里面黄色粗字带深色立体阴影，下面手写感英文。
3. **手写批注**：角落有「SC.05」镜头号、「No.134」「第 146 张」这种用红笔圈起来的计数，带手画箭头。
4. **一个小吉祥物**（比如小火苗）在标牌边上眨眼、晃动。
5. **线条每 2 帧抖一次**（boil），字按笔顺一笔一笔写出来。

## 必备元素
1. **线条沸腾**：每 2 帧换一次线稿的轻微抖动（3～4 套变体循环），静止时也在抖。
2. **一拍二**：24fps 下画面每 2 帧才更新一次（实际 12fps）；快动作可以一拍一，停住时一拍三。
3. **纸纹底**：暖白纸（`#F3EADB`）+ 纸张纹理，`multiply` 10%～15%。
4. **手绘特效**：烟团、火花、星星、速度线，也要抖。
5. **拖影帧（smear）**：特别快的动作中间有一帧把物体拉长 150%～300%。
6. **填色错位**：色块比线稿偏 3～6px，像手工上色。

## 配色（3～4 色，克制）
- 墨 `#1B1714`、番茄红 `#E5483B`、向日葵黄 `#F5B730`、纸 `#F3EADB`
- 墨 `#1E2433`、湖蓝 `#3E8ED0`、橙 `#F29F4C`、纸 `#F6EFE2`

## 字体
手写感：霞鹜漫黑 / LXGW Marker Gothic、站酷快乐体；或者把字也「画」出来（每帧抖动）。

## 动画语法
- 时间量化：`const tq = Math.floor(t * 12) / 12;` 用 tq 算所有运动位置（一拍二）
- 沸腾种子：`const boil = Math.floor(t * 12) % 3;` 每 2 帧换一套抖动
- 动作要有预备、挤压、回弹，幅度比扁平风更夸张（20%～30%）

## 技术路线
Canvas 2D。线条画法：把路径采样成点，每个点按「点序号 + 沸腾种子」加 1.5～3px 的随机偏移，再连起来；线宽也随机变一点（手绘笔触）。

```js
// 抖动描边：pts 是路径点；boil 是 0/1/2；amp 是抖动像素
function boilStroke(ctx, pts, boil, amp = 2.2, width = 6, color = '#1B1714') {
  const r = rng(boil * 977 + pts.length);
  ctx.save(); ctx.strokeStyle = color; ctx.lineCap = ctx.lineJoin = 'round';
  for (let i = 1; i < pts.length; i++) {
    const [ax, ay] = pts[i - 1], [bx, by] = pts[i];
    ctx.lineWidth = width * (.8 + r() * .4);   // 笔压
    ctx.beginPath(); ctx.moveTo(ax + (r() - .5) * amp, ay + (r() - .5) * amp); ctx.lineTo(bx + (r() - .5) * amp, by + (r() - .5) * amp); ctx.stroke();
  }
  ctx.restore();
}
// 纸纹：在 setup 里生成一张带纤维的噪点图，multiply 叠上去
```

更好的笔触（强模型）：沿路径算法线，按压力（两头细中间粗）把中心线扩成一个多边形填充，比一段段 stroke 更像毛笔 / 马克笔。

## 最小可行做法（一般模型）
1. 纸色背景 + 颗粒（`grain(ctx, t, .08)`，种子用一拍二的帧号）。
2. 主角是简单的几何形（圆脸、火苗、杯子），用 `boilStroke` 描边，填色偏移 4px。
3. 所有运动用一拍二的 `tq` 算。
4. 关键时刻加手绘爆点：一圈星星 + 3～5 条速度线，也用 `boilStroke` 画。
5. 标题用手写字体 + 每帧随机 ±1.5px 位移 / ±1° 旋转。

## 进阶做法（强模型）
- 变宽笔刷（中心线 + 压力曲线 → 轮廓多边形），线头尖、中段粗。
- 拖影帧：快速位移中间那一帧，把物体沿运动方向拉长 2～3 倍，只留 1 帧。
- 汉字标题按真实笔顺一笔笔写出来（开源的笔顺数据：hanzi-writer-data / Make Me a Hanzi，Arphic 许可，可用）。
- 烟雾：几个圆团在 1 秒内变大、变淡、向上漂，边缘也沸腾。

## 常见做砸
- 抖动太大，像画面坏了（控制在 1.5～3px）；或者每帧都换抖动（太快，像噪声）。
- 线条抖但运动是平滑的 60fps——气质不统一，运动也要一拍二。
- 用了冷色、纯白底，失去手作的温度。

## 配乐
俏皮的拨弦 / 木琴 / 爵士铺底；卡通音效：擦火柴、呼、啵、噗、闪光，和画面同帧。

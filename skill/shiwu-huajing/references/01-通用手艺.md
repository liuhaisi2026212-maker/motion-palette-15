# 通用手艺：所有风格都用得上的门道

下面的数字都是能直接用的起点。先照着用，看过效果再调。

## 1. 时间：多长、多快

30fps 下（1 秒 = 30 帧）：

| 动作 | 时长 | 说明 |
|---|---|---|
| 元素弹出（pop） | 8～12 帧 | 0 → 1.15 → 1.0 |
| 文字逐字出现的间隔 | 1～3 帧/字 | 标题 2 帧，长句 1 帧 |
| 一组元素错峰入场的间隔 | 2～4 帧 | 同时出现=死板，间隔太长=拖沓 |
| 预备动作（往反方向蓄力） | 4～6 帧 | 跳之前先蹲，冲之前先后缩 |
| 落地压扁 + 回弹 | 6～10 帧 | 见下面「挤压拉伸」 |
| 转场 | 10～15 帧 | 再长就拖了 |
| 一个镜头 / 一个信息点 | 1.5～3.5 秒 | 字多的给长一点：中文阅读速度约 5～7 字/秒 |
| 结尾停留 | 0.8～1.2 秒 | 带微动，不要完全静止 |

**帧率**：扁平、图标类用 30fps；电影感（3D、手绘）用 24fps；手绘、拼贴的主体动作再「一拍二」（每 2 帧才更新一次画面），像素精灵 10～12fps 跳帧。

## 2. 缓动：动作的灵魂

**几乎不要用线性**。每种动作配一种曲线（`u` 是 0→1 的进度）：

```js
const E = {
  outCubic: u => 1 - (1 - u) ** 3,                                   // 进场、减速停下：最常用
  inOutCubic: u => u < .5 ? 4 * u ** 3 : 1 - (-2 * u + 2) ** 3 / 2,  // 从 A 移到 B
  inCubic: u => u ** 3,                                               // 离场、加速飞走
  outBack: (u, s = 1.70158) => 1 + (s + 1) * (u - 1) ** 3 + s * (u - 1) ** 2,   // 冲过头再回来（弹性）
  outExpo: u => u >= 1 ? 1 : 1 - 2 ** (-10 * u),                     // 一下冲出去、长长地减速（玻璃、高级感）
};
// 等价的 CSS 曲线，方便对照
// 弹性回弹 cubic-bezier(0.34, 1.56, 0.64, 1)
// 中段最快（形变、移动）cubic-bezier(0.7, 0, 0.3, 1)
// 液体甩出 cubic-bezier(0.22, 1, 0.36, 1)
// 线条描绘 cubic-bezier(0.65, 0, 0.35, 1)
```

**弹簧**（比 outBack 更自然，任意时刻可直接算，适合逐帧渲染）：

```js
// t：从开始算起的秒数；f：每秒振几次（2～4）；z：阻尼（0.3 很弹，0.6 几乎不弹）
function spring(t, f = 2.5, z = 0.42) {
  if (t <= 0) return 0;
  const w = 2 * Math.PI * f, a = z * w, b = w * Math.sqrt(1 - z * z);
  return 1 - Math.exp(-a * t) * (Math.cos(b * t) + (a / b) * Math.sin(b * t));
}
```

**风格决定曲线**：扁平/花字 → 回弹；包豪斯 → `inOutQuad` 或线性，**禁止回弹**；玻璃/高级感 → `outExpo` 或正弦呼吸，**一切都慢**；液体 → 甩出曲线；像素 → 不用缓动，按帧跳。

## 3. 让动作活起来的五个原则

1. **预备**：大动作前先往反方向一点点（跳前下蹲 10%，冲前后缩）。
2. **挤压拉伸**：落地时 `scaleY 0.8, scaleX 1.15`（保持面积），起跳/高速时 `scaleY 1.15, scaleX 0.87`。幅度 10%～15%，再大就像果冻了（除非风格本身就是果冻）。
3. **回弹**：停下时冲过头 8%～15% 再回来。
4. **跟随**：主体停了，附属物（头发、尾巴、阴影、次级小球）晚 2～3 帧再停。
5. **错峰**：一组东西不要同时动，按顺序每个晚 2～4 帧；顺序有讲究（从中间往两边、从主到次、跟着视线方向）。

```js
// 错峰：第 i 个元素的进度
const stagger = (t, t0, i, gap = 3 / 30, dur = 10 / 30) => Math.min(1, Math.max(0, (t - t0 - i * gap) / dur));
```

## 4. 构图

- **主体要大**：主角或主要信息至少占画面高度的 1/4。我们见过最多的问题就是主体太小，画面显得空。
- **安全边距**：四周留 5%（横屏左右 96px、上下 54px），任何字和重要元素都不要贴边。
- **抖音竖屏**：上方 220px、下方 420px 会被界面挡住，右侧 150px 有按钮。主要内容放在 y = 300～1500 之间。
- **留白是设计的一部分**：一个画面只放 1 个焦点 + 最多 2 个辅助元素。
- **视线引导**：重要的东西放在三分线交点上，或者用运动方向把视线带过去。
- **层次**：背景（大色块/纹理）→ 中景（主体）→ 前景（少量装饰，可以虚化或半透明）。远的动得慢、近的动得快（视差比 0.6 : 0.8 : 1）。

## 5. 中文排版

- **字体**：用开源字体，不要默认宋体。推荐：思源黑体 / Noto Sans SC（正文、通用）、站酷快乐体（可爱、综艺）、霞鹜文楷 / 霞鹜漫黑（手写感）、Fusion Pixel（像素中文）、站酷高端黑（标题）。系统字体兜底写成 `"PingFang SC", "Microsoft YaHei", sans-serif`。
- **字号（1080p 横屏）**：大标题 120～180px，副标题 48～64px，正文 36～48px，角标 22～28px。竖屏同样数字基本适用。
- **粗细对比**：标题 900 / 正文 500，同一画面不要超过 2 种粗细。
- **一行最多 12～16 个字**，超了就分两行；分行时**按语意断**，不要把一个词切开，不要让第二行只剩一两个字。
- **标点**：中文用全角标点；行首不放句号逗号。
- **字距**：大标题略收（-1%～0），英文全大写小字要加宽（10%～20%）。
- **字一定要读得清**：字和背景的亮度差要大；复杂背景上的字加描边、加底条或加暗角。
- **字体加载**：用 `document.fonts.load()` 等字体加载完再开始渲染，否则会用替代字体渲染出错位。

## 6. 配色

- **一支片子 3～6 个颜色**：1 个主色（大面积）、1 个强调色（小面积、最亮）、1～2 个辅助色、深色和浅色各 1。
- **强调色只用在最重要的东西上**（主角、关键词、按钮）。
- **相邻的颜色要有亮度差**，不只是色相差：红配绿亮度接近时会糊在一起。
- **深底亮色比亮底暗色更出效果**（霓虹、玻璃、HUD）；扁平、包豪斯、科普用浅底。
- **少用纯黑 #000 和纯白 #FFF**：用很深的蓝黑（#14213D）和带一点暖的白（#FFF8EC）更高级。
- **渐变要么不用（扁平、包豪斯），要么用邻近色**（紫→蓝→青）；撞色渐变会脏。

## 7. 质感（最后加，克制）

- **颗粒**：一张 256×256 的随机噪点图，`overlay` 混合，透明度 3%～6%，每帧换偏移。能去掉渐变色带，也让画面不那么「电脑感」。
- **暗角**：径向渐变，边缘压暗 20%～40%。
- **辉光**：双层（内层窄、亮，4px；外层宽、淡，30px）。Canvas 里用 `shadowBlur` 或先画到离屏再 `filter: blur()` 叠加。
- **纸纹**：手绘、拼贴、包豪斯用，`multiply` 混合 10%～15%。
- **一个风格只加它需要的质感**，不要每样都来一点。

## 8. 转场

按优先级：

1. **元素带转场**：上一场的某个东西放大到铺满画面，变成下一场的背景（形状擦除）。
2. **匹配剪辑**：上一场结尾的形状和下一场开头的形状一样（圆点 → 太阳 → 眼睛）。
3. **运动方向延续**：东西往右飞出画面，下一场从左边进来。
4. **硬切卡节拍**：在鼓点上直接切，干脆。
5. 淡入淡出：尽量不用，最没味道。

## 9. 镜头

- 推近要慢（2～4 秒推 5%～15%），拉远揭示全貌留在结尾。
- 平移用长尾缓动（前 20% 时间走完 80% 的路）。
- 震屏只在冲击时刻用，8～12 帧衰减完，幅度 10～25px。
- 「冲击放大」（punch-in）：冲击那一帧画面放大 5%～15%，6 帧内回到原样。

## 10. 声音和画面卡点

- 先定 BPM（扁平 110～125，霓虹 100～118，花字 120～130，像素 130～150），节拍表的关键动作尽量落在拍子上：1 拍 = 60 / BPM 秒。
- 每个出现、落地、切换都配一个短音效：pop（短促上滑）、boing（弹簧）、whoosh（噪声扫频）、ding（高音正弦）、thud（低频下滑）。
- 音效与画面同帧，或者早 1 帧；花字类的字比笑点晚 2～3 帧更自然。

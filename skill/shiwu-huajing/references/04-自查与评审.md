# 自查与评审

做完不要直接交。按下面三步查，**至少改一轮**。

## 第一步：技术检查（必须全部通过）

- [ ] 时长、尺寸、帧率和要求一致（`ffprobe 文件.mp4` 或看导出页的提示）
- [ ] 有声音（如果要求了配乐），没有爆音
- [ ] 第一帧不是黑屏或空白（开头 0.3 秒内就有东西）
- [ ] 没有意外的黑帧、闪帧（转场前后各抽 3 帧看）
- [ ] 字体都正确加载（没有方块、没有变成宋体）
- [ ] 同一个时刻导出两次，画面完全一样（确定性）

## 第二步：静帧检查（用 `tools/sheet.mjs` 出拼图，或在预览页逐帧拖）

每一拍至少看开头、中间、结尾三帧。逐条问自己：

- [ ] **一眼能认出是什么风格吗？** 拿风格卡的「最容易做成不像的原因」逐条对（版式、零件、那场戏），再对「必备元素」，缺了哪个？
- [ ] **画面满不满？** 有没有大片空白、几个小元素飘在中间？这是一般做法和原版差距最大的地方。
- [ ] **主体够大吗？** 主角 / 主要信息占画面高度至少 1/4。
- [ ] **字读得清吗？** 字和背景亮度差够不够；字号够不够（横屏正文 ≥ 36px）；有没有被挡住、贴边、超出画面。
- [ ] **有没有孤字、断词、高亮被切开？**
- [ ] **颜色有没有超过 6 种？** 强调色是不是只用在最重要的地方？
- [ ] **每个画面只有一个焦点吗？**
- [ ] **有没有看起来像「默认模板」「PPT」的画面？**（白底黑字居中、系统默认字体、纯色块没有任何层次）
- [ ] **有没有直接照搬参考片子的构图、角色、文案？**

## 第三步：动态检查（正常速度看一遍，再逐帧看最快的几个动作）

- [ ] 开头 0.5 秒内有没有抓人的动作？
- [ ] 高潮在不在 60%～75% 的位置，够不够「哇」？
- [ ] 有没有死板的线性运动？进场有没有减速、停下有没有回弹（按风格要求）？
- [ ] 一组元素有没有错峰？
- [ ] 同一时刻是不是只有一个主体在做主要动作？
- [ ] 转场是不是靠元素带过去的？有没有生硬的淡入淡出？
- [ ] 结尾有没有停住 0.8～1.2 秒，并且带一点微动？
- [ ] 音效和画面对得上吗？

## 打分（可选，强模型可以让另一个会话来打）

每项 1～10 分（5 = 学生作业，6 = 模板水平，7 = 合格的专业作品，8 = 高端广告公司水平，9 = 可以拿奖）。大多数第一版在 5～7 分，不要给自己虚高。

| 项 | 看什么 |
|---|---|
| 风格还原 | 必备元素是否齐全、做得是否到位 |
| 创意 | 有没有一个清楚的想法、开头钩子、高潮瞬间、好的结尾 |
| 动画手艺 | 缓动、错峰、预备、回弹、转场 |
| 设计与排版 | 构图、层次、留白、配色、中文排版 |
| 质感 | 光、纹理、颗粒用得是否恰当，有没有色带、锯齿 |
| 声音 | 配乐风格对不对、卡点准不准 |
| 技术 | 规格、字体、有无闪帧 |

然后写 5～10 条修改意见，**按对观感影响从大到小排**。每条写清：第几秒、哪里不对、为什么、具体怎么改（用数字：缓动曲线、帧数、像素、颜色）。至少有一条是「让它更惊艳」，不只是修小毛病。

## 让另一个会话来评审的提示词（强模型用）

```
你是资深动态设计评委，这支片子不是你做的，请严格评审，客气没有用。
片子：<路径或附件>。要求的风格：<风格名>，风格卡：<贴上必备元素那一段>。
1. 每 0.5 秒抽一帧做拼图，最快的动作和高潮处逐帧看，关键帧看原尺寸细节。
2. 按上面的 7 项打分，不要虚高。
3. 给出 5～10 条修改意见，按影响从大到小排，每条写清时间、问题、原因、具体改法（带数字）。
4. 单独标出：看起来像模板/AI 套版的地方、中文不自然的地方、字体问题、规格问题。
```

拿到意见后回到制作会话：先保存当前版本，再逐条改，改完重新导出、重新检查，并说明哪些改了、哪些没改、为什么。

# 版权与素材：做片子前后要守的规矩

这一页写给你（AI），也写给用这个 skill 的人。片子要发抖音、接商单、给客户交付，下面这些都要过一遍。

> 这是做事的规矩，不是法律意见。涉及大额商单或已经有纠纷时，请咨询律师。

## 一、风格可以学，具体作品不能抄

- **风格本身不受著作权保护**：「扁平矢量」「赛博 HUD」「像素风」这些是一类做法，谁都能用。版式规律、配色思路、节奏、手法，都可以照着风格卡学到位。
- **具体作品受保护**：别人片子里的具体画面、角色形象、文案、构图、配乐，不能照搬，也不能「换个颜色就算自己的」。
- 所以本 skill 的规矩是：**风格照卡学，内容自己做**——主体、文案、角色、具体构图、配乐都是新的。用户拿一支别人的片子说「做个一样的」，要学它的做法，换掉它的内容，并跟用户说清楚为什么。

## 二、字体：先看能不能商用

| 字体 | 能不能用在商用视频里 | 能不能放进项目分发 |
|---|---|---|
| OFL 字体（思源黑体 / Noto Sans SC、霞鹜系列、站酷系列、Google Fonts 里的大多数） | 能 | 能，要附许可文本 |
| 厂商免费字体（阿里巴巴普惠体、HarmonyOS Sans、抖音美好体等） | 一般能，以各家授权页为准 | 多数不允许，**不要打包**，让用户自己下载 |
| 系统字体（苹方、微软雅黑、Helvetica 等） | 授权跟着操作系统走，没有明确写可以商用 | 不能 |
| 网上下的不明来源字体、「破解版」字体 | **不要用** | 不能 |

做法：
- 片子的 `font-family` 里，**把 OFL 字体写在前面**（中文首选 `"Noto Sans SC"` / 思源黑体），系统字体只当后备。
- 给客户交付或做商单时，确认导出时实际用的是 OFL 字体（缺字体时浏览器会悄悄换成系统字体，截一帧看看）。
- 用了哪些字体，写进交付说明。

## 三、图片、照片、图标

- 只用：用户自己的、CC0 / 公有领域的（如 Openverse、Wikimedia Commons 里标 CC0 / PD 的）、授权写明可商用的。
- 不用：搜索引擎随手搜来的图、别人的作品截图、影视剧截图、明星照片。
- **别人的品牌 logo、商标、IP 角色**（米老鼠、马里奥、Hello Kitty、各大品牌标志等）不要放进片子。像素风的主角、贴纸风的吉祥物都自己画。
- 能用代码画的就用代码画——本 skill 的样片几乎都是这么做的，也最省心。

## 四、音乐和音效

- 首选：用脚手架的合成器写（`starter/lib/core.js` 的 `Mix`），完全是自己的。
- 也可以：用户自己有授权的曲子，或者平台（抖音等）自带曲库——注意平台曲库通常**只能在该平台内使用**，导出带到别处可能不行。
- 不用：流行歌、影视原声、从别的视频里扒的音轨。

## 五、文案和数据

- 品牌名用用户自己的；用户没给就**编一个**，并确认没撞上知名品牌。
- 科普、测评类片子里的数字要有出处；拿不准的标「示意」「数据仅供参考」（样片「一杯奶茶多少糖」就是这么做的）。
- 商业推广片避免「最」「第一」「国家级」这类绝对化用语，不要做对比贬低别家的说法。

## 六、发布到平台

- 用 AI 生成的视频，按《人工智能生成合成内容标识办法》（2025 年 9 月 1 日起施行）和平台规则，**发布时勾选「内容由 AI 生成」之类的声明**。
- 商单要按平台要求走报备 / 标注「广告」。

## 七、交付时附一张「来源清单」

每次交付在说明里写清楚：

```
字体：Noto Sans SC（OFL）、站酷快乐体（OFL）
图片：全部代码绘制 / 用户提供的 logo.png / Openverse CC0：xxx（链接）
音乐：代码合成
品牌名：用户提供「xxx」
数据：xxx 出处 / 示意
```

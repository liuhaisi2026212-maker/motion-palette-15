# 十五画境 · 创作版

每种风格是一套**零件库**：画法、动画手法、转场、配乐都做好了；**讲什么、分几个镜头、每个镜头演什么、配什么字**由你根据用户的主题来定。所以每次做出来的都是新片子。

## 你要做的

1. 问清楚（或从用户的话里提取）：主题、给谁看、想让观众记住的那句话、大概多长、横屏还是竖屏、有没有照片。
2. 选风格：
   - `pixel` 像素风（16:9）：有「过程」的主题，闯关、升级、打怪、开宝箱
   - `flat` 扁平矢量（16:9）：讲道理、讲方法、做对比的知识类内容
   - `variety` 综艺花字（9:16 竖屏）：抖音口播、生活分享；可以用用户自己的照片当背景
3. 写镜头表（JSON）。每种风格有哪些镜头类型、每种要填什么，见 `lib/kits.js`，或者在工作台点「复制给AI的提示词」看完整说明。`kits/<风格>/example.js` 是完整示例。
4. 出片：
   - 能跑命令：`node lib/server.mjs`，浏览器打开 http://127.0.0.1:7916/ ，把 JSON 贴进右边，点「导出 MP4」。
   - 不能跑命令：把 JSON 给用户，让用户双击 `启动创作版` 打开工作台，自己粘贴、导出。

## 写镜头表的规矩

- 先有故事：钩子 → 讲清楚 → 结论 / 引导关注。6~10 个镜头，每个 2~4 秒。
- 相邻镜头换类型；字数不能超过每个字段的限制。
- 文案说人话、不要错别字；用用户自己的名字和品牌。
- 只用列出来的镜头类型和字段。工具会尽量容错，但不认识的类型会被替换。

## 想要更多变化（强模型）

零件库是开放的：每个风格的镜头函数在 `kits/<风格>/kit.js` 的 `SHOTS` 里，可以照着现有的写新镜头类型（保持「给时间 t 就画出那一帧」，不用随机时钟），再在 `lib/kits.js` 里登记字段说明。

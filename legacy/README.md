# 历史版本（已停止维护）

这里是十五画境早期试过、后来放弃的两条路线，留作对照。**要用请看仓库根目录的 [README](../README.md) 和 [`skills/shiwu-huajing/`](../skills/shiwu-huajing/)。**

| 目录 | 是什么 | 为什么放弃 |
|---|---|---|
| `v0.3-模板版/` | 直接拿开源项目 mg-styles-15 的 15 支原片，把文字和配色抽成配置，改配置就能导出 | 画面和原片一模一样，只换了字，等于搬运别人的作品 |
| `创作版/` | 像素、扁平、综艺花字三套零件库，写一份镜头表就能生成新片 | 换主题也还是那几套零件，本质仍是模板 |
| `v0.3-模板版打包.py` | 模板版的打包脚本 | 随模板版一起停用 |

两条路线的问题，促成了现在的做法：不给模板，而是把每种风格「怎么做才对味」写成手艺书，让 AI 按你的主题从头写原创片子。

模板版的来源与许可见 `v0.3-模板版/CREDITS.md`、`v0.3-模板版/LICENSE`。

# 十五画境 · Motion Palette 15（v0.3 开发中）

15 种 MG 动画风格的**模板版** skill：每种风格是一支做好的高质量短片（来自 [mg-styles-15](https://github.com/Vincentwei1021/mg-styles-15)，MIT），文字和配色抽成了配置。用任何 AI（包括豆包、DeepSeek）写一份配置，就能得到同样质量的品牌短片。

进度见 [进度记录.md](进度记录.md)。

- `work/demos/<风格>/`：每支片的源码，`index.orig.html` 是改之前的原版
- `work/mp/cfg.js`：读取配置的公共代码
- `work/harness/render.mjs`：逐帧渲染成 MP4（来自原项目）

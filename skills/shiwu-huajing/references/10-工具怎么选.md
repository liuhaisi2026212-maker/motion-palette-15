# 工具怎么选：按画面需要挑，各渲各的，最后拼起来

一支片子不必只用一个工具。每一镜按它要的效果挑最顺手的工具，各自做好，最后在 `lib/reel.js` 里接起来，声音也在那里统一混。

## 1. 什么画面用什么

| 画面要的 | 用 | 说明 |
|---|---|---|
| 扁平图形、线条、图标、文字动画、像素、贴纸、大多数风格 | **Canvas 2D**（默认） | 最稳，每一帧只由时间决定，`starter/` 全套工具都围着它 |
| 真 3D：立体字、城市、产品模型、灯光材质、景深 | **Three.js** | 在 `film.html` 里用 importmap 引入（要联网，想离线就把文件下载到本地改路径）；在 `draw` 里渲好再画到 Canvas 上。完整例子：`examples/films/3d-render-泡芙工作室/` |
| 发光、液体、折射、噪声流动 | **WebGL 着色器** | 强模型用；一般模型用 Canvas 的模糊和发光近似 |
| video-shotcraft 某张镜头卡正好是你要的动作（发牌、叠卡、数据跳动、界面推近、标题入场、转场） | **Remotion**，单独渲成 MP4 | 用 `tools/remotion.mjs`，见第 3 节 |
| 已经有的视频：录屏、实拍、别的工具做好的镜头（HyperFrames、剪映导出等） | **`lib/clip.js`** 把 MP4 当一段片子 | 能参与转场，声音一起混 |

拿不准就用 Canvas 2D。只有 Canvas 做不出、或者做出来明显差一截的镜头，才换别的工具。

## 2. 怎么拼

所有工具最后只有两种形态：

- **网页里直接画的**（Canvas、Three.js、着色器）：本来就是一个 `{ draw(ctx, t), audio() }` 的片子对象。
- **一个 MP4**（Remotion、HyperFrames、录屏、实拍）：用 `clip()` 包成片子对象。

然后一起放进 `reel()`：

```js
import { reel } from './lib/reel.js';
import { clip } from './lib/clip.js';
import opening from './films/01-opening.js';    // Canvas 做的
import outro from './films/03-outro.js';        // Three.js 做的
const deal = await clip('shots/DeckDealFlyin.mp4');   // Remotion 渲的镜头卡
export default reel([
  { film: opening },
  { film: deal, cut: { type: 'flash' } },
  { film: outro, cut: { type: 'pushcut', dur: .4 } },
], { bpm: 120 });
```

`clip()` 的选项：`start`（从视频第几秒开始）、`duration`（用多长）、`fit`（`'cover'` 铺满裁边，`'contain'` 完整放下补黑边）、`audio`（要不要视频里的声音）。视频帧率和片子不同也没关系，每一帧都按时间去取。

导出、体检照旧：`node tools/render.mjs`、`node tools/check.mjs`。

## 3. 用 video-shotcraft 的镜头卡（Remotion）

```bash
node tools/remotion.mjs setup              # 第一次：建 remotion/ 副工程，下载镜头卡，装依赖（要联网、要 git）
node tools/remotion.mjs add deck-deal-flyin   # 把卡的代码拷进来，在 remotion/src/Root.tsx 里登记
node tools/remotion.mjs render DeckDealFlyin  # 渲成 shots/DeckDealFlyin.mp4
```

镜头卡固定在一个核对过的版本，依赖版本也锁死了，换电脑装出来的一样。渲染优先用这台电脑上已有的无头 Chrome，没有的话 Remotion 会自己下一份。

**拷进来以后一定要改，不能原样用**：

1. **先读卡**：`remotion/shotcraft/references/shots/<类>/<卡名>.md`，上面写了这个镜头的意图、关键参数和已知的坑。
2. **换品牌**：卡里的示例品牌叫 video-shotcraft，画面上会出现它的名字和标志。代码画出来的标志和名字，改 `remotion/src/_fixtures/Brand.tsx` 一处就能全换。**但有十几张卡用了原仓库自带的示例截图**（`remotion/public/textures/live/` 和 `remotion/src/_textures/` 里的 png，比如 deck-deal-flyin、crash-zoom-punch、spotlight-hero-card、page-waterfall-wall、outro-group-photo-launch 这几张），截图上直接画着 video-shotcraft 的标志和假界面，改 Brand.tsx 换不掉：要么换成你自己的截图（同名替换），要么别用这些卡。卡的代码里搜 `staticFile` 或 `_textures` 就知道它用没用截图。
3. **换配色**：配色在 `remotion/src/_fixtures/Look.tsx` 的 `LOOKS` 里。改成和片子其他段同一套颜色（可以照 `starter/lib/looks.js` 的色值抄过去），不然拼起来像两支片子。
4. **换文字和示例界面**：卡里的示例文字、假界面数据写在卡的代码和 `_fixtures/Fixtures.tsx` 里，换成你自己的内容。
5. **尺寸和帧率别动**：卡按 1920×1080、每秒 30 帧调的，坐标都是写死的。片子是 60 帧也能直接拼。
6. **镜头卡没有声音**：音效和配乐在 `reel` 那边用 `Mix` 统一配。

渲好以后用 `node tools/sheet.mjs` 或直接抽几帧看一眼，确认品牌和颜色都换掉了再拼。

## 4. 许可

- **video-shotcraft 的镜头卡**：代码是 Apache-2.0，允许商用和改编。两件事要做到：
  - 交付的源码里带上 `remotion/shotcraft/LICENSE`（Apache 要求随改编后的代码附许可原文），改过的卡在文件开头注明改过；来源清单写「部分镜头改编自 video-shotcraft（Apache-2.0）」。
  - 原仓库的 `references/shots/ATTRIBUTION.md` 写明：有一批卡（38 张）的手法是研究别人公开的宣传片、项目主页后**从零重写**的，原作者没有授权复刻。重写的手法本身一般可以用，但不要把画面做得和那些原片一模一样。用到这批卡之前看一眼那份文件，给客户做商用片时把这一点告诉用户。
- **Remotion**：个人、非营利组织、员工不超过 3 人（含 3 人）的公司免费；更大的公司做商业用途要买许可。用户是公司的话，交付时提醒一句，许可条款以 https://www.remotion.dev/license 为准。用户不方便用 Remotion，就照卡上写的手法和参数用 Canvas 重写，卡本身的思路是可以借的。
- **Three.js**：MIT，可以商用。

## 5. 常见坑

- **视频拼进来只显示开头几帧**：本地服务不支持按段读取视频时会这样。`clip()` 已经先把整支视频读进内存再放，不用自己处理；如果你绕过 `clip()` 自己用 `<video>`，就会碰到。
- **转场时透出上一段**：每一段（包括 `clip` 包的视频）开头先铺满自己的背景。`clip()` 会先铺黑底。
- **Remotion 渲染卡住或报找不到浏览器**：第一次渲染 Remotion 要下载无头 Chrome，网络不好会很慢。装过 Playwright 或 HyperFrames 的电脑会直接用已有的那份。
- **混了工具以后风格对不上**：颜色、字体、动效性格要三边一致。改完拼起来，用 `node tools/compare.mjs` 和改之前并排比一下。

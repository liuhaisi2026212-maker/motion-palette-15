# 动画手艺进阶：从「会动」到「好看」

`01-通用手艺.md` 讲的是基本功：缓动、错峰、预备、回弹。照着做，东西就会动得顺。
这一篇讲的是下一步：怎么让观众觉得「这个动画做得好」。工具都在 `starter/lib/motion.js`。

很多数字来自几个成熟开源项目的实测和总结（LottieFiles motion-design-skill、HyperFrames、Remotion、Motion Canvas、Orkas VideoStudio，见 `NOTICE.md`）。`starter/film.js` 示例把下面大部分手法都用了一遍，可以对照着看。

先说最常见的差距。下面是一般做法和好做法的对比：

| 一般做法 | 好的做法 |
|---|---|
| 东西出现了，然后一直停着 | 出现 → 停住时还在微微呼吸 → 离场时有自己的动作 |
| 每段都从空画面开始搭 | 上一段留下一个东西，带进下一段 |
| 镜头是死的 | 整段在慢慢推近，冲击时刻猛地放大一下 |
| 所有东西走直线 | 走弧线，快的东西有拖影或拉伸 |
| 一个动作做完，下一个才开始 | 前一个动作还没停稳，下一个就开始了（重叠 20%～30%） |
| 文字淡入 | 文字被遮罩擦出来、一行一行推上来、逐字弹出 |
| 每拍一样长 | 快拍、慢拍交替；重点拍放长、停住 |

## 1. 每个画面都要有三层动

1. **主动作**：这一拍的主角在做的事（弹出、落地、变形）。同一时刻只有一个。
2. **跟随动作**：被主动作带起来的东西，晚 2～4 帧才停，比如阴影、尾巴、小粒子、旁边被震动的元素。
3. **环境动**：背景、装饰在很慢地漂、呼吸、旋转，幅度很小（几个像素、1% 的缩放）。

只要第三层一直在，画面就不会「卡住」。用 `idle(t, 种子, 幅度)`：

```js
const f = idle(t, 3, 6);   // 每个元素种子不同，就不会一起晃
ctx.save(); ctx.translate(x + f.x, y + f.y); ctx.rotate(f.r); ctx.scale(f.s, f.s); 画元素(); ctx.restore();
```

`tools/check.mjs` 会把超过 1.5 秒完全不动的段落报出来。

## 2. 镜头：静止画面立刻有生气

整段慢推 3%～8%，冲击时刻放大 5%～10% 再弹回，大冲击加一点震屏：

```js
camera(ctx, t, { push: [B.title.t0, B.title.t1, 1, 1.05], punch: [[B.title.t0 + .4, .08]], shake: [[B.title.t0 + .4, 14]] });
画这一场();
ctx.restore();   // camera 里 save 了，这里配对 restore
```

- 背景和前景可以各套一层镜头，推的幅度不同（背景 1.03、前景 1.08），就有了纵深。
- 冲击放大和震屏**只给最重要的那一两下**。每拍都震，观众会累，也就不觉得重要了。作用在整个画面上的冲击（整屏放大、震屏、闪白）**全片不超过 3 处**，两处之间隔开至少 8 秒；其余拍点只让主角自己动。
- 包豪斯、玻璃、线条这类克制的风格只用慢推，不用震屏。

## 3. 一个元素的完整生命：进场、停住、离场

东西不要凭空消失。用 `life(t, 进场时刻, 离场时刻)`：

**例外：段与段之间不要先退场。** 上一段先淡出、下一段再进场，等于「黑一下的硬切」。转场本身就是上一段的退场：转场开始时上一段的画面是满的，两段同时动（见第 8 节）。这一节说的是同一段里的元素。

```js
const L = life(t, B.tip.t0, B.tip.t1 - .25);
if (L.alive) { const s = L.in * (1 - L.out); ctx.save(); ctx.translate(x, y - L.out * 120); ctx.scale(s, s); 画(); ctx.restore(); }
```

离场比进场快：离场时长是进场的 65%～75%（进场 10～12 帧，离场 7～8 帧），用加速曲线（`E.inC`）。离场方向最好就是下一个东西进场的方向，视线就被带过去了。

## 4. 关键帧：写出有起伏的动作

一串 `seg + lerp` 很难写出「冲过去 → 回来一点 → 停 → 再离开」。用 `keys`：

```js
const x = keys(t, [[0, -300], [.35, 560, E.outBack], [1.6, 560], [1.9, 1400, E.inC]]);
const [px, py] = keys(t, [[0, [100, 900]], [.6, [540, 700], E.outC]]);   // 二维也行
```

**节奏的秘诀是「快—停—快」**：快速到位（6～10 帧）→ 停住让人看清（0.5～1.5 秒）→ 快速离开。慢吞吞地一直在动，看起来反而没劲。

## 4.5 时长、距离和物理

- **时长跟着距离走**：以移动 100px 为基准，200px 乘 1.3，400px 乘 1.6，横穿整个画面乘 1.8～2。远距离用同样的时长，就会显得太快、太冲。
- **一次移动不超过画面的 1/3**；更远的路程中途要改方向、变速或走弧线。**三个以上元素时，同一刻在动的不超过 1/3**。
- **物理弹簧**：`springTo(t - t0, SPRINGS.plop)`，预设有 plop（弹出）、bounce（一直弹）、swing（摆）、jump（起跳）、strike（敲击）、smooth（顺滑几乎不弹）、beat（卡拍子的一下）。比自己调 `spring(f, z)` 省事，手感也更像。
- **材质决定手感**：金属 1.2 倍时长、不过冲；橡胶 0.8 倍、过冲 15%～25%；水 1.5 倍、过冲 5%；纸 1 倍、过冲 3%～5%；烟 2 倍、不过冲。
- **先定一种动效性格，整片 90% 以上都用它**：

| 性格 | 视频里单个动作时长 | 曲线 | 过冲 | 适合的风格 |
|---|---|---|---|---|
| 俏皮 | 0.3～0.5 秒 | 回弹（`E.outBack`、plop） | 10%～20% | 花字、扁平、3D 软萌、像素 |
| 高级 | 0.6～1.0 秒 | `bezier(0.4, 0, 0.2, 1)`、`E.outExpo` | 0 | 玻璃、线条、包豪斯 |
| 稳重 | 0.4～0.6 秒 | `bezier(0.2, 0, 0, 1)` | 0～3% | 科普贴纸、等轴 |
| 燃 | 0.2～0.4 秒 | `E.outExpo`、strike | 15%～30% | HUD、霓虹、综艺高潮 |

## 5. 弧线和速度感

- 真实的运动几乎都走弧线：`arc(u, 起点, 终点, 0.25)`，抛物、甩出、飞入都用它。
- 快的东西在运动方向上拉长 10%～20%，停下的一瞬间压扁（`squash`）。
- **动态模糊**（最像「丝滑」的那一样）：
  - 只给快动作：每帧移动超过自身宽度的猛冲、甩出、急停、快速放大、旋转，一支片子 1～3 处。慢漂、呼吸、淡入淡出不要模糊，会显得糊、廉价。
  - 字只模糊飞来的过程，落地那一刻必须清楚，然后停住让人读。
  - 单个元素：`blur(ctx, t, fps, (c, tt) => 画它(c, tt), { box: [x, y, w, h], frames: 1 })`。`box` 是它可能出现的范围，越小越快；`frames: 1` 拖影短而利落，`2` 是 After Effects 的默认长度。
  - 整帧（甩镜头、铺满画面的转场）：片子对象里写 `motionBlur: { windows: [[t0, t1]], samples: 16 }`，只在这几段时间开。边缘每帧走几百像素时，采样提到 24～32，否则会看到一圈圈台阶。
- 不想算模糊时，退一步画 2～3 个半透明残影（上一两帧的位置，透明度 0.3、0.15）。
- **放大要用感知缩放**：`pscale(从, 到, 进度)`。按倍数匀速放大，越大看起来越慢；按面积匀速，眼睛才觉得匀速。圆形铺满画面的转场尤其明显。
- **整组挪位置用慢快慢**：`nudge(t, t0, 时长)`。起步 20% 的时间走 10% 的路，冲刺 18% 的时间走 65%，收尾 62% 的时间走 25%。任何一条现成曲线都会「啪」地撞停。新内容放在冲刺那一段出现，正好被动作带出来。
- **反向动作**：主体往左，背景往右轻挪（速度是主体的 20%～30%）；主体落下，影子变大变实；主体放大，影子缩小。画面会更稳、更有分量。

## 6. 重叠，不要排队

动作和动作之间**不要等前一个完全做完**：

- 标题还在回弹（最后 20%）时，副标题就开始进场。
- 一组卡片错峰进场，间隔 2～4 帧，每张自己 10～12 帧：同一时刻有三四张在动，看起来就像一阵浪，而不是一张一张地摆。
- `stagger(t, t0, i, { n, gap, dur, order: 'center' })`：从中间往两边比从左到右更有冲击力。

## 7. 文字的动法

字是信息的主体，动法决定了片子像 PPT 还是像动画：

| 手法 | 什么时候用 |
|---|---|
| 逐字弹出（`popText`） | 花字、扁平、贴纸类的标题 |
| 遮罩擦出：字从一条线后面升上来 | 高级感、包豪斯、玻璃 |
| 一行一行推上来，上一行同时被推走 | 连续的几句话 |
| 打字机 + 光标 | HUD、像素、终端 |
| 数字滚动（`counter`） | 数据：一定用它，位数提前留好，单位不会被压住 |
| 关键词单独变色 / 放大 / 加底线 | 一句话里只有一个词重要时 |

**字出现后要停够读完的时间**：中文每秒约 5～7 个字，再加 0.5 秒。想让观众记住的那个画面（品牌名、结论、关键数字），落定后完整停住至少 1 秒。

**第一版节奏默认放慢一档**：第一版几乎总是偏快，很少有人嫌慢。排时间表时先给停住的时间留足，再往里塞动作。

## 8. 段与段之间：接住，而不是重来

- **带过去**：上一段的某个东西（圆点、色块、主角）放大、变形，成为下一段的第一个画面。
- **匹配**：上一段结尾的形状和下一段开头的形状一样（圆 → 太阳 → 气泡）。
- **方向延续**：往右飞出，下一段从左进；往下掉，下一段从上落。
- **卡拍子硬切**：在鼓点上直接切，切之前一帧画面最满，切之后一帧最空，反差越大越带劲。
- 拼合集时用 `lib/reel.js` 的 `cut`（`pushcut` / `zoom` / `iris` / `push` / `wipe` / `bars` / `flash`），见 `08-单风格与合集.md`。
- **整片选一种主转场**，六七成的切点都用它，再配一两种点缀；同一种转场不要连用三次以上。
- **按位置选转场**：
  - 开场：最有辨识度的那种，0.4～0.6 秒；
  - 相关内容之间：主转场，约 0.3 秒；
  - 换话题：换一种；
  - 高潮：最猛的；
  - 收尾前：回到柔和，0.5～0.7 秒；
  - 结尾：最慢最简单，0.6～1 秒。
- **按能量选时长**：平静 0.5～0.8 秒（正弦曲线），中等 0.3～0.5 秒，高能 0.15～0.3 秒。

## 9. 和声音一起设计

- 先定 BPM，每个重要动作落在拍子上：`const beat = 60 / bpm`，时间写成 `n * beat`。
- **音效比画面早 10～20 毫秒**（耳朵比眼睛快）：`m.pop(B.title.t0 - .015)`。几个音效叠在一起时，要分在高、中、低不同频段。
- **冲击的那一帧，画面、镜头放大、音效三样同时到。** 这一下对上了，观众就觉得「爽」。
- 安静一拍再炸：高潮前 0.3～0.5 秒把音乐和画面都收一下（只留一个音、画面变暗或变空），再一起炸开。

## 10. 竖屏（抖音、视频号）的特别规矩

- **前 1 秒必须有一句大字**，至少 80px，放在画面中上部（y = 400～900）。这一句就是「为什么要看下去」。
- 想让观众读的句子至少 44px，关键句 56px 以上。HUD 那种装饰小字可以小，但不能用来放信息。
- 底部 420px、顶部 160px、右侧 140px（y 在 800 以下）会被平台界面挡住，重要的字不要放进去。
- 字和背景同色系（粉配粉、红配红）一定会糊：换深浅相反的颜色，或用 `readable()` 自动加描边 / 底板。反差至少 4.5 : 1，手机上很大的字可以放宽到 3 : 1。
- **第一帧就是封面**：平台缩略图、观众划到时看到的都是它。要有一句读得出「这条讲什么」的大字和主体。
- 跑 `node tools/check.mjs`，上面这些都会自动查出来。

## 自查：这支片子的动画够不够好

- [ ] 随便暂停在哪一帧，画面里都有东西在动（至少环境层）
- [ ] 每个元素都有进场和离场，没有凭空消失
- [ ] 至少有一处镜头动作（慢推或冲击放大），且对在节拍上
- [ ] 一组元素是一阵浪，不是排队
- [ ] 段与段之间至少有一半是「接过去」的，不是每段从空白重来
- [ ] 快—停—快：重要信息停得够久，过渡够快
- [ ] 高潮那一下：画面最满、镜头冲击、声音最响，三样同一帧
- [ ] 最快的一两下有动态模糊，字落地是清楚的
- [ ] 远距离移动更慢、离场比进场快、整组挪位用了慢快慢
- [ ] 整片一种动效性格、一种主转场

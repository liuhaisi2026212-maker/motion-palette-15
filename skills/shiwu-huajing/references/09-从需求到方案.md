# 从需求到方案：用户说想要什么感觉，你来定怎么做

用户常常不点名风格，只说一种感觉：「要有科技感、有冲击力」「温柔一点」「高级」「像发布会」。这时候风格、手法、工具都由你来定。风格不限于风格卡上那十几种，也不限于一个工具。

这一页讲的是动手写代码之前的这段：把一句话变成一张能照着做的分镜表。分镜定了，再回到 `SKILL.md` 完整流程的第 5 步（先做静帧）往下走。

## 1. 先定两种做法里的哪一种

| 做法 | 什么时候用 | 你停下来问几次 |
|---|---|---|
| **全权做**（默认） | 用户只说了要什么，没说要参与 | 不停。每一步自己拍板，把理由记下来，交付时一起说 |
| **共同创作** | 用户说「先给我看方向」「一步步来」「我想一起定」，或者片子要公开发布、给客户交 | 停 3 次：简报、方向静帧、分镜表。每次只问 1～3 个真定不了的事 |

拿不准就用全权做。交付时把每个决定和理由写清楚，用户不满意哪一条就改哪一条。

## 2. 需求简报：你先填，再问

不要把一张空表丢给用户填。每一行先写你的判断和依据，定不了的才问。

```
| 项 | 我的判断 | 依据 |
|---|---|---|
| 用途、发在哪 | B 站和视频号的产品宣传片 | 用户说「宣传片」，没说平台，横屏两边都能发 |
| 给谁看 | 用 AI 工具的上班族和开发者 | 产品是 AI 工具 |
| 看完要记住的一句话 | 「XX：一句话把活干完」 | 用户给的卖点 |
| 想要的感觉（用户原话） | 科技感、冲击力 | 原话照抄，后面翻译成参数 |
| 时长、画幅 | 30 秒，1920×1080 | 用户说的 |
| 必须出现的东西 | 产品名、三个功能、结尾 logo | 用户给的材料 |
| 素材、品牌色 | 没有，品牌名和配色我来定 | 用户没给 |
| 声音 | 电子底 + 少量落点音效，不做密集音效 | 片子要冲击力，但音效不能噼里啪啦 |

要问的：1. 产品叫什么？（不知道就编一个，交付时说明）
```

- 「看完要记住的一句话」必须有。用户没给就从他的话里提一句，交付时请他确认。
- 「想要的感觉」原话照抄。这一行决定后面所有参数，不能自己改写成别的词。

## 3. 把「感觉」翻译成动效参数

感觉放到两根轴上看：

- **沉稳 ↔ 有劲**：管快慢、过冲、压扁的幅度。
- **严肃 ↔ 活泼**：管路线直还是弯、小动作多还是少、颜色收还是放。

用户的词怎么落到轴上（用户自己说的词优先，画面线索其次）：

| 用户常说 | 沉稳 ↔ 有劲 | 严肃 ↔ 活泼 |
|---|---|---|
| 科技感、未来感、发布会 | 偏有劲 | 偏严肃 |
| 冲击力、燃、炸、帅 | 很有劲 | 中间 |
| 高级、质感、大气、克制 | 偏沉稳 | 偏严肃 |
| 专业、可信、靠谱 | 沉稳 | 严肃 |
| 可爱、萌、好玩 | 中间 | 很活泼 |
| 温柔、治愈、安静 | 很沉稳 | 偏活泼 |
| 搞笑、综艺、热闹 | 有劲 | 很活泼 |

落到两根轴上以后，从最近的一种动效性格起步（性格和参数的完整表见 `07-动画手艺进阶.md` 第 4 节）：

| 位置 | 性格 | 单个动作 | 过冲 | 压扁 | 镜头和转场 |
|---|---|---|---|---|---|
| 沉稳 + 严肃 | **稳重** | 0.4～0.6 秒 | 0～3% | 不压 | 慢推、平移，硬切或遮罩 |
| 偏沉稳 + 偏严肃 | **高级** | 0.6～1.0 秒 | 0 | 不压 | 长推、景深，光扫、慢溶 |
| 有劲 + 严肃 | **燃**（偏机械） | 0.2～0.4 秒 | 5%～15%，急停 | 很少 | 冲击放大、甩镜、闪白，最多 3 处震屏 |
| 有劲 + 活泼 | **燃**（偏综艺） | 0.2～0.4 秒 | 15%～30% | 15%～25% | 冲击放大、弹出、撞色转场 |
| 沉稳 + 活泼 | **俏皮**（慢一档） | 0.5～0.7 秒 | 5%～10% | 5%～8% | 软推、圆形遮罩 |
| 中间 + 活泼 | **俏皮** | 0.3～0.5 秒 | 10%～20% | 10%～18% | 弹出、圆形遮罩、贴纸飞入 |

定下来以后，把这一行写进分镜表顶上，整片 90% 以上的动作都用它。自查两件事：

1. 用三个词形容做出来的动效，和用户的原话对得上吗？
2. 入场、转场、停顿是不是同一套参数？一半弹一半不弹，看起来像拼盘。

**例外**：东西从高处落地、被拍扁，这类有物理含义的动作该弹就弹，哪怕整片是「稳重」。

## 4. 选风格

三种情况：

1. **风格卡里有对得上的**：直接用。看 `styles/00-选风格.md` 的速查表或在线速查页，按「适合 / 不适合」「能量」「动效性格」筛。
2. **要混两种**：一种当主风格（占 70% 以上的画面），一种当点缀（比如主风格是赛博 HUD，数据那一段用等轴 2.5D）。两种风格的配色要先统一到一套色板上，不然像两支片子剪在一起。超过两种就是合集了，按 `08-单风格与合集.md` 做。
3. **风格卡里没有**（用户要水墨、要黏土、要某部片子那种感觉）：先照 `styles/_新风格卡模板.md` 写一张新卡，找 2～3 支参考片拆出它的版式、零件和戏，再动手。写卡这一步不能省，省了就会做成「大概像」。

配色：风格卡有自己的色板，用它的。混风格、新风格、或者用户有品牌色时，从 `starter/lib/looks.js` 的通用色板挑一套起步，再按品牌色改强调色。

## 5. 选手法

先列出片子要讲的几件事（一个产品就是开场、三个功能、收尾），每件事配一个手法。手法从两个地方挑：

- **十五画境自己的**：风格卡里的关键手法，`07-动画手艺进阶.md` 和 `starter/lib/motion.js` 里的镜头、错峰、转场遮罩、动态模糊。
- **video-shotcraft 的镜头卡**：124 张，按用途分了类（开场、列一组东西、数据、转场、收尾……），每张写了意图、参数和坑。在线预览：https://vincentwei1021.github.io/video-shotcraft/ 。要用就按 `10-工具怎么选.md` 的办法单独渲染再拼进来。

规则：

- **一种手法全片只当一次主角**。三个功能用三种不同的动法，不要三段都是「卡片飞入」。
- **整屏冲击全片最多 3 处**，彼此隔开 8 秒以上。
- 卡多不等于往里堆。每个手法都要能说出「它在这里帮观众看懂了什么」。

## 6. 方向静帧

不要直接做动画。先做 2～3 个方向，每个方向 2 张 1920×1080 的静帧（开场一张、高潮一张），截图放在一起看：

- **全权做**：自己挑一个，在交付说明里写一句为什么选它、为什么不选另外两个。
- **共同创作**：把并排的图给用户挑。

方向之间要真的不同（配色、材质、构图至少差两样），不是同一张图换个颜色。只换色板出来的三张图，看起来是同一个方案，挑不出东西。

代码里的颜色全部从色板对象取（`L.accent`、`L.text`……），不要在光晕、冲击波、描边里写死 `rgba(77,124,255,…)`：写死的颜色换方向时不会跟着换，挑出来的静帧就不准。

## 7. 分镜表

最后写成分镜表，一镜一行。每一镜只有一个主要动作。

```
动效性格：燃（偏机械）　主色板：midnight　主转场：光扫 + 硬切
| 时间 | 画面 | 主动作 | 用什么做 | 落定后停 | 声音 |
|---|---|---|---|---|---|
| 0.0–2.5 | 黑底，一道光扫出产品名 | 光扫出字 | Canvas | 0.8 秒 | 低频起 |
| 2.5–6.0 | 三张功能卡发牌飞入 | 发牌 | Remotion 卡 deck-deal-flyin | 1.0 秒 | 每张一下轻落点 |
| ...    |  |  |  |  |  |
| 26–30 | 全片元素收拢成 logo | 收拢 + 一次冲击 | Canvas | 1.2 秒 | 重落点后留白 |
```

排的时候守这几条（详见 `00-工作流程.md` 和 `07-动画手艺进阶.md`）：

- 开头 0.5 秒内就有东西在动。
- 关键信息落定后停至少 1 秒，让人读完。
- 高潮在全片 60%～75% 处；结尾是全片能量最高或最稳的一下，不要虎头蛇尾。
- 第一版节奏放慢一档。看过之后再提速，比做快了再拉慢容易。
- 「用什么做」这一列见 `10-工具怎么选.md`。

分镜表定了，回到 `SKILL.md` 完整流程第 5 步（先做静帧），每一镜照常走静帧 → 动画 → 声音 → 体检。

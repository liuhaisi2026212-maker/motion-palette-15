# 模型不太强时，怎么做到「像样」

做不出好看的片子，大多不是因为写不出复杂代码，而是因为**想做的太多，每样都只做了一半**。下面这条路线专门用来避开这个问题。

## 规则

1. **只用 Canvas 2D**。不碰 WebGL、Three.js、SVG 滤镜、HTML 图层。
2. **直接改 `starter/film.js`**，不要从空文件开始。保留它的结构：节拍表 → 每一拍一个函数 → `draw` 分发 → 最后加质感。
3. **只用 `lib/core.js`、`lib/draw.js`、`lib/motion.js` 里已有的函数**画东西：`text`、`readable`、`popText`、`fancyText`、`counter`、`rrect`、`circle`、`star`、`burst`、`speedLines`、`grain`、`vignette`、`glow`、`cover`、`pixelText`、`sprite`；动起来用 `keys`、`stagger`、`camera`、`idle`、`life`。
4. **一支片子 4～6 拍，总长 8～15 秒**。
5. **每个风格只做它风格卡里「最小可行做法」那 3～4 条**，每条都做到位。不要去碰「进阶做法」。
6. **颜色直接用风格卡给的配色**，不要自己调。
7. **动画只用三种**：进场用 `spring`（弹出）或 `E.outCubic`（滑入）；移动用 `E.inOutCubic`；离场用 `E.inCubic`。
8. **每写完一拍，就出一张静帧看**（预览页拖到那一秒）。有问题当场改，不要攒到最后。
9. **每一拍都套一个 `camera(ctx, t, { push: [t0, t1, 1, 1.05] })` 慢推**，停住的元素加 `idle`。这两样最省事，效果最明显。
10. **导出前跑 `node tools/check.mjs`**，报告里除了装饰小字，其余全部改掉。
11. **要做几种风格的合集**：每种风格单独写一个 `films/xx.js`，各自过检查，再用 `reel` 拼（`08-单风格与合集.md`）。不要把 15 种风格写进一个大函数里。

## 步骤

1. 写节拍表（文字），4～6 拍，每拍：时间、画面、字、声音。
2. 打开风格卡，抄下「最小可行做法」和「配色」。
3. 改 `film.js` 顶部的 `TEXT`、`PALETTE`、节拍表 `beats([...])`。
4. 一拍一拍写函数。每个函数只画这一拍的东西，时间用 `seg(t, B.xxx.t0, B.xxx.t0 + 0.4)` 这种写法。
5. 在 `audio()` 里改 bpm 和音效时间（直接引用节拍表）。
6. 打开预览页，逐拍检查（`04-自查与评审.md` 第二步）。
7. 导出。

## 写代码时最容易错的地方

- 忘了 `ctx.save()` / `ctx.restore()` 成对，导致后面的东西全歪了、全透明了。
- `globalAlpha` 设了忘了改回 1。
- 坐标算错跑到画面外：先写死在画面中间，看到了再挪。
- 字太长溢出：用 `text(ctx, s, x, y, { maxW: 1400 })` 自动换行，或 `fitSize` 自动缩字号。
- 滚动数字后面跟单位：用 `counter(ctx, t, t0, 1.2, 100, x, y, { unit: '件' })`，不要自己拼。
- 字放在花背景或同色背景上：用 `readable()` 代替 `text()`。
- 时间写成了绝对秒数，改节拍表后全乱：一律用 `B.xxx.t0 + 偏移`。

## 交付时要说的

- 用了风格卡里哪几个手法，分别在第几秒。
- 哪些风格特征没做（比如「没有做真正的液体融合，用的是圆形叠加近似」）。
- 用户想改字、改颜色，改 `film.js` 顶部哪几行。

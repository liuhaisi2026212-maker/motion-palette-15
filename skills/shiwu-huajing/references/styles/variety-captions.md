# 综艺花字（抖音竖屏）

## 一眼认出它
综艺节目、抖音 vlog 后期那种情绪化的字：胖胖的字带好几层描边（彩色 + 白 + 深色厚度），弹一下出来，配爆炸框、速度线、汗滴、问号、印章、警示条；画面在冲击时刻会震一下、放大一下。

## 适合 / 不适合
适合：抖音口播、生活 vlog、萌宠、访谈、搞笑、知识类的情绪点。不适合：高级感品牌片。

## 最容易做成「不像」的原因（先看这个）
只有彩色背景 + 花字，没有「主体」——那是字幕模板，不是综艺包装。对照原版，味道来自：
1. **画面里一定有一个主体**（人、宠物、产品），而且做成**贴纸**：抠图 → 一圈 18px 白边 → 外面再一圈 6px 深蓝细边 → 背后一张锯齿撕纸。贴纸放在放射底上，周围有一组组短黑弧线（强调线）轮流闪。
2. **包装零件要多、要分层**：栏目牌（黄色胶囊 + 深蓝粗边 + 粉色期号，开场大、之后缩到左上角常驻）、人物名牌（歪着放：深色小签「本期主讲」+ 大花字名字 + 黄色小签头衔）、警示条（黄黑斜纹边框 + 红字 + 两个警告三角）、检测仪表（白卡 + 粉色标签 + 彩虹半圆 + 指针甩过头）、相框卡（白边相片斜放，里面再一层放射底 + 主体）、圆形印章（双圈 + 环形英文 + 中间两行字 + 斑驳）、四角闪光星星。
3. **爆炸框是双层的**：外层粉、内层黄，深蓝描边，花字压在上面歪着放。
4. **结尾两行渐变花字**：上面大号粉紫渐变（紫色外描边），下面黄橙渐变（粉色外描边）的「关注我～」。
5. 背景在两种之间切：蓝白斜条纹（开场、结尾）和粉黄放射（主体镜头）。

没有照片时：自己画一个吉祥物（几何形 + 简单表情，准备 2～3 种表情），按上面的方法做成贴纸。参考作品：`examples/films/variety-周一早上/film.js`（里面有 `stickerize`、`tornPaper`、`stampCanvas`、`gauge`、`hazardBar`、`nameplate` 的完整写法）。

## 必备元素
1. **多层描边花字**：渐变字面 + 粗白描边 + 彩色外描边 + 深色立体厚度（或投影）。用 `starter/lib/draw.js` 的 `fancyText`。
2. **弹性入场**：0 → 1.15 → 1.0，约 8 帧；或逐字弹跳，每字晚 2 帧，带一点歪斜。
3. **情绪匹配**：惊讶 → 爆炸框 + 速度线 + 震屏；尴尬 → 汗滴 + 竖排「空气突然安静」；吐槽 → 歪斜的手写小字「（小声）」；强调 → 警示条、印章、仪表盘爆表。
4. **冲击感**：关键时刻画面放大 5%～15%（6 帧回落）+ 震屏 10～25px（10 帧衰减）+ 一帧闪白。
5. **停留时轻微晃动**（wiggle），字不能死在那里。
6. **高饱和撞色**：粉、黄、青、红 + 白描边。
7. **竖屏安全区**：上 220px、下 420px、右 150px 留空。

## 配色（花字墨水）
- 阳光：字面 `#FFF7B0`→`#FFB800`，内描边白，外描边 `#E8462B`，厚度 `#8A1E10`
- 甜粉：`#FFE3F1`→`#FF4FA0`，外描边 `#7A1BD8`，厚度 `#3B0A6E`
- 天蓝：`#E6FBFF`→`#22C8F5`，外描边 `#1543B8`，厚度 `#0A1F5C`
- 警告红：`#FFE0D6`→`#FF3B30`，外描边 `#1B1B1B`

## 字体
站酷快乐体（圆胖、可爱）、思源黑体 Heavy（爆炸字）、霞鹜漫黑（手写吐槽）。都开源可商用。

## 背景
用户自己的照片 / 视频截图：铺满（`cover`），缓慢推近（每秒 1%～2%），底部加一层黑色渐变让字更清楚。没有照片就用彩色花纹底（放射条、斜条纹、波点，在两种高饱和颜色之间）。

## 技术路线
全部 Canvas 2D。

```js
// 冲击时刻：放大 + 震屏，作用在背景上
const hit = (t, t0) => { const d = t - t0; return d < 0 ? 0 : Math.max(0, 1 - d / .25); };
const punch = .12 * hit(t, BOOM_T), shake = 22 * Math.max(0, 1 - (t - BOOM_T) / .35) * (t > BOOM_T ? 1 : 0);
const r = rng(Math.floor(t * 30)); ctx.translate((r() - .5) * 2 * shake, (r() - .5) * 2 * shake);
cover(ctx, photo, 0, 0, 1080, 1920, 1.06 + .02 * t + punch);
// 爆炸框 + 速度线 + 花字
speedLines(ctx, 540, 1150, Math.floor(t * 15)); burst(ctx, 540, 1150, 380 * E.outElastic(seg(t, BOOM_T, BOOM_T + .7)), 14, '#FFE45E');
fancyText(ctx, '答非所问！', 540, 1150, 190, { top: '#FFE0D6', bot: '#FF3B30', outer: '#1B1B1B', deep: '#000' }, { rot: -.08 });
// 逐字弹出（开场大字）
popText(ctx, '你真的会用AI吗', 540, 1240, t, .15, { size: 160, color: '#FFB800', stroke: '#fff', strokeW: 26, gap: 2 / 30, tilt: .05 });
```

## 最小可行做法（一般模型）
1. 背景：用户照片缓慢推近；没照片就放射条纹彩色底。
2. 每 2～2.5 秒一个花字时刻，按情绪选：开场大字（逐字弹）、字幕条（打字机）、爆炸框（震屏）、汗滴 + 小声吐槽、印章、结尾关注按钮。
3. 每个时刻都配一个音效（pop / boing / 爆炸低音 / 盖章咚）。
4. 左上角一个栏目名小牌子贯穿全片。

## 进阶做法（强模型）
- 花字跟着画面里的人或物（照片里标出位置，字和箭头指过去）。
- 仪表盘指针甩到爆表、竖排大字一个个砸下来、警示条从两边滑入、印章带印泥斑驳。
- 字的出现比笑点 / 语音晚 2～3 帧（如果有口播音频）。

## 常见做砸
- 没有主体，只有背景和字。
- 零件太少、太平：一个镜头只放一句字。
- 字放在抖音界面会挡住的地方（底部、右侧）。
- 描边太细，在照片上看不清。
- 每个字都一样的颜色和效果，没有情绪变化。
- 全程都在震，没有轻重。

## 配乐
轻快的综艺垫乐（拨弦 + 贝斯 + 拍手，120～130 BPM）；音效：boing、pop、叮、滑哨、唱片刮擦（问号时）、爆炸低频（震惊时）。

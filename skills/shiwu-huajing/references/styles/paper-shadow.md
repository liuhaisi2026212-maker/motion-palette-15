# 剪纸皮影

## 一眼认出它
一块被油灯从后面照亮的**幕布**：中间暖黄发亮，四周压成深棕，灯火一直在轻轻跳。上沿挂一排扇贝边的帘子，两角坠着流苏。幕布底下是**红纸剪的海水纹**，三层叠着，每层纸边都有一点厚度阴影。一个**黑色皮影人**从一边走进来：身子、头、胳膊、腿都是分开的皮子，关节处钉着铆钉，身上剪满镂空花纹，灯光从花纹里透出来；三根细杆从脖子和两只手一直伸到画面外面。高潮是一张**折起来的红纸团花一瓣一瓣展开**，最后书法大字一个个写出来，盖一方红印。

一句话：**灯、幕、杆、镂空——观众要一眼看出「这是有人在幕后操纵的纸」。**

## 适合 / 不适合
适合：国风品牌、传统节日、非遗文化、讲历史故事、讲中国传统、年货礼盒、戏曲、民俗。不适合：科技产品、数据讲解、快节奏的潮流内容。

## 最容易做成「不像」的原因（先看这个）
1. **皮影人是一整块黑剪影**：那只是「影子」，不是皮影。皮影的味道全在**镂空**（胸口团花、袍子竖纹、腰带小孔、帽子一排孔、眼睛一条缝）和**关节**（每个关节一圈小孔当铆钉，各部件绕铆钉转）。没有镂空、身体不分块，就不像。
2. **没有操纵杆**：杆是「有人在操纵」的证据。至少三根：脖子一根粗的，两只手各一根细的，一直伸出画面下沿，跟着手动。
3. **背景是平涂的纯色**：幕布必须是**被灯从后面照**的样子——径向渐变，中间最亮、四周压暗，亮度一直有很小的起伏（灯火在跳）。
4. **剪纸没有厚度**：红纸要用离屏画布剪出镂空（`destination-out`），画的时候加一点投影，看起来是一张张叠起来的纸，而不是平面图形。
5. **动作太顺滑、太快**：皮影走路是「一颠一颠」的：身子上下跳、微微前后摇，四肢绕关节甩。整片节奏要慢，停住的时候也跟着灯火轻轻晃，不能完全静止。

## 必备元素（缺一个就不像）
- 被灯从后面照亮的幕布，亮度一直轻轻跳
- 分块、有关节铆钉、身上剪满镂空的皮影人
- 至少三根伸出画面的操纵杆
- 带纸厚度阴影的红色剪纸（海水纹、祥云、团花至少两样）
- 书法字 + 红印章

| 秒 | 发生什么 |

| 0.35～0.95 | 帘子从上面落下，略微回弹；流苏跟着晃几下停住 |
| 0.7～1.6 | 三层海水纹依次升起，之后一直缓缓左右流动 |
| 1.1～2.2 | 两朵祥云从左右滑进来 |
| 1.5～4.3 | 皮影人从左边一颠一颠走进来，走到画面偏左站定；每两步一声梆子 |

| 4.75～5.75 | 折起来的一瓣团花弹出来，一瓣一瓣转开成一整朵（每开一瓣一声拨弦，音往上走） |

## 配色
- 幕布：`#FFE7B0`（中心）、`#F4AE52`、`#B9531B`、`#3A1206`（边）
- 皮影：`#160906`（不要纯黑，偏一点红棕）
- 剪纸：深红 `#8E1B18`、正红 `#C8231F`、浅红 `#DE4A35`
- 印章底 `#C8231F`，印章字 `#FBEBC8`；副标题 `#4A1408`

## 字体
- 标题和印章：马善政毛笔楷书（Ma Shan Zheng，OFL），文件在 `examples/assets/fonts/MaShanZheng-Regular.ttf`
- 副标题：`"Noto Serif SC"` 宋体，字距拉开（`ctx.letterSpacing`）

## 动画语法
动效性格是**稳重**（`07-动画手艺进阶.md` 第 4 节），单个动作 0.5～0.9 秒，基本不过冲；例外是有物理含义的动作：帘子落下、手往上扬、印章盖下去，允许一点回弹。皮影人身上的动作全是**绕关节转**：先算出每个关节的角度，再从身子往外一节节画。走路时身子上下颠（`|sin|`）、前后小摇，两条腿和两只胳膊反向甩。灯火亮度用两层不同快慢的 `noise1` 叠起来。

## 技术路线
- 全部 Canvas 2D。所有剪纸和皮影部件在 `setup` 里画进离屏画布一次：先填形状，再用 `globalCompositeOperation = 'destination-out'` 剪镂空。之后每帧只是 `drawImage` 加旋转平移，很快。
- 皮影部件：每块皮子记一个转轴（ox, oy），画的时候 `translate(关节位置)` → `rotate(角度)` → `drawImage(皮子, -ox, -oy)`。胳膊：肩 → 大臂 → 肘 → 小臂，手的位置用三角函数推出来，接操纵杆。
- 操纵杆：画完皮影人以后用 `ctx.getTransform()` 把手和脖子的位置换算到屏幕坐标，再画到画面下沿外面。
- 皮影人加 `shadowBlur` 16 左右的深色柔边，像贴在幕布上的影子。
- 团花：只画一瓣（45°），转 8 次摆成一圈；展开时第 k 瓣的角度是 `k × 45° × 进度`。

## 最小可行做法（一般模型）
1. 径向渐变幕布 + 暗角，亮度乘一个 `1 + 0.05 × noise1(t × 6)`。
2. 底部两层红色半圆浪（离屏画布剪两道弯月），加投影。
3. 皮影人只分三块：身子（带头）、前胳膊、后胳膊；身子上剪 5～6 个镂空，胳膊绕肩转；画两根杆。
4. 结尾书法字逐字出现 + 一方红印。

## 进阶做法（强模型）
- 头、身子、两只胳膊各两节、两条腿全部分开，加走路、举手、鞠躬三组动作。
- 团花一瓣瓣展开，每瓣配一声拨弦。
- 灯光里加浮尘，慢慢往上飘。
- 多个皮影人对戏：近处的大而清楚，远处的小、虚一点、颜色淡一点（离幕布远）。

## 常见做砸
- 皮影人身上没镂空，或者镂空太小，缩小以后看不见：镂空线宽至少 4px，团花孔至少 10px。
- 部件之间转动不连着：关节位置算错，胳膊转起来和身子脱开。先只画关节点调对再贴皮子。
- 剪纸颜色太多：红色系三种深浅就够，别加绿、蓝。
- 音效太密：拨弦和梆子都要稀，一秒不超过两下。

## 配乐
五声音阶的拨弦（三角波 + 高八度的正弦，快起慢收）+ 低音长音铺底 + 很稀的梆子；团花全开时一记低沉的锣，结尾拨弦落回主音。速度 80～90 BPM。整体加一点回声。

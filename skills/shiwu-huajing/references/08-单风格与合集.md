# 单风格出片，或者几种风格拼成一支

用户常见的三种要法：

| 用户说 | 做法 |
|---|---|
| 「用像素风做一支 15 秒的片头」 | **单风格**：一支片子一种风格，就是默认流程 |
| 「每种风格各做 5～10 秒，拼成一支」 | **合集**：每段单独做成一支小片子，再用 `lib/reel.js` 在代码里拼 |
| 「我手上已经有几支 MP4，帮我接起来」 | **接视频文件**：`tools/join.mjs` |

不管哪种，**每一段都按完整流程做**（节拍表 → 风格卡 → 静帧 → 动画 → 声音 → 检查）。合集不是把 15 张海报摆一遍，每一段自己就要是一支像样的小片子。

## 单风格

就是 `SKILL.md` 的完整流程，写在 `starter/film.js` 里。时长 10～20 秒最合适。

## 合集：先分段做，再在代码里拼

### 目录

```
starter/
  films/
    01-hud.js        每段一个文件，导出的东西和 film.js 完全一样
    02-variety.js
    ...
  film.js            只负责把各段串起来
```

每段文件里 `import` 路径写 `../lib/core.js`。每段第一行先铺满自己的背景，否则转场时会透出上一段。

### 逐段做、逐段查

- 预览某一段：打开预览页时在地址后面加 `?film=films/01-hud.js`。
- 检查某一段：`node tools/check.mjs --film films/01-hud.js`。
- 导出某一段：`node tools/render.mjs out/01-hud.mp4 --film films/01-hud.js`。用户想要「单独每一种」，就把每段各导出一支。

每段都过了检查再拼。

### 拼起来

```js
// film.js
import { reel } from './lib/reel.js';
import { backing } from './lib/core.js';
import hud from './films/01-hud.js';
import variety from './films/02-variety.js';
import pixel from './films/03-pixel.js';

export default reel([
  { film: hud },
  { film: variety, cut: { type: 'flash' } },
  { film: pixel, cut: { type: 'iris', dur: .4, x: 540, y: 900 } },
], { bpm: 120 });
```

- `cut` 写的是「从上一段进入这一段」的方式：`cut` 硬切、`flash` 硬切加白闪、`iris` 圆形放大、`wipe` 斜擦、`bars` 横条、`push` 推屏（`dir` 写新画面从哪边进）。
- 写了 `bpm`，切点会自动吸到最近的拍子上。
- 转场期间两段同时在画：上一段走它最后 `dur` 秒，下一段走它最前 `dur` 秒。
- 声音：每段自己的 `audio()` 按位置混进来，最后整体拉到 -14 LUFS。想要一条贯穿全片的底乐，传 `bed: (m, dur) => backing(m, dur, { bpm: 120 })`，各段的声音会自动压低一点让位。
- 想让某一段在合集里短一点：`{ film: pixel, dur: 4 }`，只用它的前 4 秒。

### 合集的讲究

1. **时长不要平均分。** 15 段每段 3.4 秒，看起来就是在翻幻灯片。按内容分：
   - 开头钩子那段 4～5 秒，前 1 秒就要有大字；
   - 讲事的段落 3～5 秒；
   - 纯展示的过渡段 1.5～2.5 秒；
   - 高潮段 5～6 秒；
   - 结尾停 1.5～2 秒。
   `tools/check.mjs` 发现每段几乎一样长时会提醒。
2. **用一条线串起来。** 一个贯穿的角色、一个圆点、一种颜色、一句话的分段，让观众知道这是「一支片子」，不是 15 支拼盘。
3. **至少一半的接口要「接得住」**：上一段结尾留一个形状，下一段从这个形状开始（同一位置、同一颜色），再用 `iris` 或 `push` 过去。剩下的在鼓点上硬切。
4. **同一个 BPM。** 所有段的音乐和动作都卡同一个拍子，风格再跳，节奏也是连着的。
5. **每段都要有自己的「那一下」。** 只有 3 秒，也要有一个最强的瞬间，放在这一段的 60% 左右。
6. **每段画面都不要从空白开始搭。** 一切进来时，画面里就已经有东西了（主体已经在、背景已经铺满），再加动作。
7. **竖屏合集的字统一放在同一个区域**（比如 y = 1200～1450），观众的视线就不用每段重新找。

## 接视频文件

只有导出好的 MP4，没有源码时：

```
node tools/join.mjs out/合集.mp4 a.mp4 b.mp4 c.mp4            # 硬切
node tools/join.mjs out/合集.mp4 a.mp4 b.mp4 c.mp4 --fade 0.3 # 段间交叉淡化 0.3 秒
```

尺寸以第一段为准（其它段自动缩放、补边），声音统一拉到 -14 LUFS。能在代码里拼就别用这个，代码里的转场好看得多。

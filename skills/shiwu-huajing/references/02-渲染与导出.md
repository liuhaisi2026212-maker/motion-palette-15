# 渲染与导出

## 核心约定：给时间 t，画出那一帧

整支片子是一个函数 `draw(ctx, t)`：同一个 t 永远画出同一个画面。这样才能：逐帧导出不卡顿、随时拖到任意一秒检查、和配乐严格对齐。

**要做到这一点：**
- 不用 `Date.now()`、`performance.now()`、`requestAnimationFrame` 的时间，只用传进来的 t。
- 不用 `Math.random()`，用 `starter/lib/core.js` 的 `rng(种子)`；需要每帧变化的随机（抖动、颗粒），用帧号当种子：`rng(Math.floor(t * 24))`。
- 物理、粒子不要「上一帧 + 速度」累加，要写成 t 的公式（抛物线 `y = y0 + v*t + g*t*t/2`、弹簧 `spring(t)`）。
- 不用 CSS 动画和 CSS transition。

## 脚手架怎么用（`starter/`）

```
starter/
  index.html     预览与导出页：播放、拖时间轴、逐帧看、导出 MP4（带配乐）
  film.html      片子页面（字体在这里声明）
  film.js        ← 你主要写这个
  lib/core.js    时间、缓动、弹簧、挤压拉伸、随机数、节拍表、配乐合成器
  lib/draw.js    文字（换行、逐字弹出、花字）、形状、颗粒、暗角、辉光、照片、像素工具
  lib/server.mjs 本地服务
  tools/sheet.mjs   关键帧拼图（自查用）
  tools/render.mjs  命令行导出 MP4（需要 ffmpeg）
  启动.command / 启动.bat   双击打开预览页
```

`film.js` 导出一个对象：

```js
export default {
  width: 1920, height: 1080, fps: 30, duration: 10,      // 竖屏写 1080 × 1920
  fonts: [['900 100px "ZCOOL KuaiLe"', '片子里用到的所有字']],   // 先加载字体再渲染
  async setup(canvas) { /* 可选：预先加载图片、生成纹理、算好路径 */ },
  draw(ctx, t) { /* 画第 t 秒 */ },
  audio() { /* 可选：返回 Mix().master() 的结果 */ },
};
```

写法建议（看 `starter/film.js` 示例）：
1. 用 `beats([['hook', 1.5], ['title', 2.5], ...])` 定节拍表，所有动画都写成 `seg(t, B.title.t0, B.title.t0 + .4)` 这种相对时间。改节奏只改节拍表。
2. 每一拍一个函数（`drawHook`、`drawTitle`……），`draw` 里按时间分发。
3. 质感（颗粒、暗角）放在最后统一加。

## 预览和导出

**能跑命令的话：**

```bash
cd starter
node lib/server.mjs            # 或 python3 -m http.server 7920
# 浏览器打开 http://127.0.0.1:7920/ ，点「导出 MP4」
```

或者全命令行（需要 Chrome 和 ffmpeg，第一次先 `npm install puppeteer-core`）：

```bash
node tools/sheet.mjs                 # 出 12 格关键帧拼图到 out/sheet.png，自己看一遍
node tools/sheet.mjs 0.5,2,4.25,8    # 指定时刻，单张图存在 out/stills/
node tools/render.mjs out/成片.mp4    # 逐帧导出，带配乐
```

**不能跑命令（只能聊天）的话**：把完整的 `starter` 文件夹（含你写的 film.js）交给用户，告诉用户：
1. 双击 `启动.command`（苹果电脑）或 `启动.bat`（Windows），浏览器会自动打开预览页。电脑要装 Node.js 或 Python。
2. 点「导出 MP4」，等进度条走完。用最新版 Chrome 或 Edge。
3. **不能直接双击 film.html 打开**：浏览器不允许本地文件加载模块，会白屏。

## 选什么技术画

- **Canvas 2D**（首选）：形状、文字、图片、像素都能画，导出最稳。
- **SVG**：线条描绘（`stroke-dashoffset`）很方便，但浏览器里导出要先转成图片。建议用 `Path2D(svg路径字符串)` 在 Canvas 里画，路径长度用 `SVGPathElement.getTotalLength()` 预先算好。
- **WebGL / 着色器**：液体、发光、折射、大面积模糊。在 `setup` 里建一个 WebGL 画布（`preserveDrawingBuffer: true`），每帧渲染完 `ctx.drawImage(glCanvas, 0, 0)` 拷到主画布上。
- **Three.js**：真 3D。同样渲染到自己的画布，再拷到主画布。从 CDN 或本地引入固定版本。
- **不要用 HTML/CSS 图层拼画面**：浏览器里没法把 HTML 元素逐帧变成视频（Chrome 会拒绝），只能靠无头浏览器截图。

## 动态模糊（可选，强模型）

快速运动的东西加一点模糊会更真实：同一帧在 t 前后各取几个时刻画，叠在一起取平均。

```js
// 在 draw 外层：samples=4，shutter=0.5 帧
for (let k = 0; k < 4; k++) { const tt = t + ((k + .5) / 4 - .5) * .5 / 30; ctx.globalAlpha = 1 / (k + 1); drawFrame(off, tt); ctx.drawImage(off.canvas, 0, 0); }
```

只在快动作的几帧用，全片都用会很慢。

## 配乐

`core.js` 里的 `Mix` 是一个纯数学的小合成器：`tone(开始秒, 时长, 频率, {wave, vol, env, slide, pan})`，再加 `kick / snare / hat / pop / boing / whoosh / ding / thud` 这些现成音效，`backing()` 一行生成一段四拍子伴奏。

```js
audio() {
  const m = new Mix(DURATION + .3);
  backing(m, DURATION, { bpm: 118, root: 62 });   // 底鼓、军鼓、和弦、贝斯、琶音
  m.thud(1.0); m.pop(1.6); m.whoosh(3.8, .4); m.ding(6.5);   // 卡在画面节拍点上
  m.echo(); return m.master();
}
```

各风格的配器建议见风格卡。用户自己有音乐的话，用 `fetch` + `decodeAudioData` 读进来，返回同样的 `{ sampleRate, left, right }` 结构即可。

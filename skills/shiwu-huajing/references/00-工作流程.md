# 工作流程：从一句主题到一支片子

## 1. 先把需求问成这 6 件事

| 项 | 没说时的默认 |
|---|---|
| 主题 / 想让观众记住的一句话 | 必须问，不能编 |
| 给谁看、在哪发 | 抖音 / 视频号 → 竖屏 1080×1920；B 站 / 官网 → 横屏 1920×1080 |
| 时长 | 10～15 秒（片头、开场）；讲解类 20～40 秒 |
| 风格 | 给 2～3 个候选让用户选 |
| 品牌名、logo、配色 | 有就用；没有就编一个品牌名，配色按风格卡 |
| 素材（照片、视频截图） | 有就用，没有就纯代码画 |

## 2. 写节拍表（这一步决定片子好不好看，比写代码重要）

先用文字写，不写代码。格式：

```
00.0–01.5  钩子：（画面）一颗珊瑚色圆点从顶上掉下来，落地压扁再弹起　（字）无　（声）咚
01.5–04.0  推进：圆点变成太阳，下面一栋栋楼依次长出来　（字）「每天进步一点点」　（声）楼落地的嘀嗒声
04.0–06.5  高潮：……
06.5–08.5  收尾：所有元素收拢成 logo + 标语，停 1 秒，轻微呼吸
```

写节拍表时守这几条：

- **开头 0.5 秒内必须有东西在动**。黑屏或空画面超过 0.3 秒，观众就划走了。
- **整片只有一个想法**。10 秒的片子只讲一件事，所有画面为它服务。
- **高潮放在全片 60%～75% 的位置**。那一刻要有一个「哇」的瞬间：最大的变化、最强的颜色、最响的声音。
- **结尾停住 0.8～1.2 秒**，留一点微动（呼吸、闪光），让观众看清品牌名或结论。
- **转场靠元素带**：一个东西飞出去、放大、变形，顺势把画面带到下一场；不要用淡入淡出。
- **快慢要有对比**：忙的段落和静的段落交替，全程一样快会让人累，全程一样慢会让人睡着。
- **每个风格卡的「必备元素」都要落到具体某一秒**，写在节拍表里。

## 3. 定技术路线

看风格卡里的「技术路线」。大原则：

| 画面类型 | 用什么 |
|---|---|
| 扁平图形、线条、图标、文字 | Canvas 2D（最稳）或 SVG |
| 像素风 | Canvas 2D，小画布整数倍放大 |
| 发光、模糊大光斑、液体、折射 | WebGL 片元着色器（强模型）；一般模型用 Canvas 的 `filter: blur()` 和 `shadowBlur` 近似 |
| 真 3D（立体字、城市、地球） | Three.js（强模型）；一般模型用 2.5D 假立体（多层平移叠影） |
| 照片 + 花字 | Canvas 2D 画照片，花字用多层描边 |

**一般模型优先全部用 Canvas 2D**，少用 HTML/CSS 图层：CSS 图层浏览器里没法直接逐帧导出（见踩坑清单）。

## 4. 先静帧，再动画

1. 在 `starter/` 里写好每一场的 `draw(ctx, t)`，先不管动画，所有元素放在最终位置。
2. 用 `starter/tools/stills.mjs`（或在预览页拖时间轴）截 4～6 张关键时刻。
3. 拿 `04-自查与评审.md` 的「静帧检查」逐条看：主体够不够大、字够不够清楚、留白、配色是否超过 5～6 个颜色、有没有元素贴边被裁。
4. 静帧过关了，再加动画。

## 5. 动画

- 先做主体动作（谁从哪到哪），再加次级动作（跟随、回弹、小粒子），最后加质感（颗粒、辉光、暗角）。
- 一次只让一个主体做主要动作，其他元素要么不动，要么只有很小的呼吸。
- 用 `01-通用手艺.md` 的缓动和时长表，不要全用线性。

## 6. 声音

- 用 `starter/lib/audio.js` 的合成器，或者用户提供的音乐。
- 节拍表里的每个「落地」「弹出」「切换」都配一个短音效，比画面早 0～1 帧或同步。
- 配乐响度：峰值不超过 -1 dB，整体听起来不吵。

## 7. 导出、自查、改一轮

- 导出 MP4（`02-渲染与导出.md`）。
- 抽帧检查（`04-自查与评审.md`），**至少改一轮**再交付。强模型可以让另一个会话按评审表打分，拿意见回来改。

## 8. 交付说明的格式

```
风格：扁平矢量
时长 / 尺寸：12 秒，1920×1080，30fps，带配乐
节拍：00.0 圆点落地 → 01.5 城市生长 → …
必备元素落点：弹性缓动（全程）、元素错峰（01.5–03.0 楼房）、色块转场（06.5）……
已知不足：角色手臂动作比较僵；字体用的是系统黑体
怎么改：改 film.js 里的 TEXT 常量换文案；改 PALETTE 换颜色
```
